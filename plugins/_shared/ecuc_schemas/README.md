# AUTOSAR CP ECUC schema packs

Curated EcucDefs-shaped JSON for AUTOSAR Studio BSW configurator (R20-11 short names).

Each `Module.json` drives:

- starter stubs (`stub_from_schema`)
- Add / Remove / Duplicate multiplicity
- typed parameter editors + Spec tips
- DEFINITION-REF paths `/AUTOSAR/EcucDefs/<Module>/…`

Not a vendor BSWMD GCE host. Edit packs to deepen containers; no stack codegen.

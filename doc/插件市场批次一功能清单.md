# 插件市场 · 批次一功能清单与 32 插件规格

> 生成日期：2026-08-23
> 状态：批次一开发需求基线（作为插件开发的需求来源）

## 一、目标与方法

对市面上主流 CAN/CAN FD 工具的高频功能点做分层统计（应用层 / 协议层 / 行业 / 总线工程 / 数据库工程 / 日志工程 / 安全测试 / 可视化），形成功能清单；剔除主程序已有能力（Trace 报文窗口、Graphic 曲线、Watcher 信号监视、过滤引擎、录制回放）与已发布 5 款插件（uds-diagnostic / blf-converter / bus-statistics / dbc-tool / canopen-explorer）已覆盖的能力，得出批次一 32 款插件规格。

## 二、市面高频功能点清单（需求来源）

### 2.1 诊断应用层（最高频）
- OBD-II 车辆自诊断：模式 01 动态数据（PID）、02 冻结帧、03/07 故障码读取、04 清码、09 车辆信息、MIL 状态
- UDS (ISO 14229) ECU 发现：诊断地址扫描、服务探测、负响应地图
- UDS 批量测试：请求脚本批量执行、结果导出（对标 CANdela/ODX 测试序列）
- UDS 安全审计：SecurityAccess 种子采集与规律分析、会话/时序检查
- ISO-TP (ISO 15765-2) 链路被动监视：多帧重组、会话表、FC 参数

### 2.2 商用/行业协议层
- SAE J1939：PGN/PGN 解码、SPN 值、传输协议（BAM/RTS-CTS）重组、地址声明、DM1 故障码
- GB/T 27930（国标充电）：CHM/CRM/BRM/BCP/BRO/BCL/BCS/BSM/CST/CML 报文解析与充电状态机
- NMEA 2000（船舶）：PGN 解码（航向/航速/位置/风速）、Fast Packet 重组
- ISO 11783 ISOBUS（农机）：地址声明、TC/BAS/VT 报文监视
- CANopen 补充：节点在线扫描（SDO 0x1018 Identity 探测 + 心跳发现）
- XCP/CCP（标定）：CONNECT/GET_STATUS/DIY DAQ 基本监视、轮询测量
- AUTOSAR CAN NM：0x400-0x4FF 网络管理报文监视、节点状态机（Bus-Sleep/RepeatMessage/Normal/ReadySleep）

### 2.3 总线工程（发送/仿真/网关）
- 手动/周期报文发送器（PCAN-View 发送窗口、ZCANPro 发送）——DBC 感知、序列、Hex 编辑
- 节点仿真（Restbus 轻量版）：按 DBC 周期发送、信号值模式（恒值/递增/正弦/随机）
- 报文网关/转发器：ID 映射改写、载荷补丁、限频转发
- 压力/鲁棒性测试：突发洪泛、畸形 DLC/FD 帧（对标 CANoe Stress Program）

### 2.4 总线分析
- ID 发现与分类 + DBC 增量审计（总线上有而库中没有的、库中有而总线上没有的）
- 逆向工程位活动分析（SavvyCAN bit-gravity / 比特翻转矩阵，信号边界推断）
- 双源比对（实时 vs 实时、日志 vs 日志：ID/载荷/时序差异）
- 触发记录（条件触发 + 环形预触发缓冲 + 后触发窗口）
- 总线体检报告（负载、Top Talker、周期稳定性、DBC 覆盖率、空闲率，导出报告）

### 2.5 DBC 数据库工程（canmatrix/cantools 族）
- DBC diff（报文/信号/属性级差异）
- DBC merge（多库合并 + ID/名字冲突检测）
- DBC 导出（信号矩阵 CSV/JSON）
- DBC → C 代码生成（pack/unpack，Intel/Motorola，signed/factor/offset）
- DBC 静态检查（lint：命名规范、重叠信号、越界、缺属性）

### 2.6 日志工程
- 日志工具箱：ASC/CSV/BLF 拆分、合并、时间裁剪、ID 过滤、脱敏
- （格式转换已由 blf-converter 覆盖，不重复）

### 2.7 安全测试
- CAN 模糊测试（随机/结构化变异、限速、ID 范围选择）
- CAN 入侵检测（白名单、速率异常、载荷熵、伪装检测）
- E2E 保护校验（CRC8/16/32、SAE J1850、AUTOSAR E2E alive counter）

### 2.8 可视化与计算工具
- 实时仪表盘（仪表盘/柱状/数字部件，DBC 信号驱动）
- 位时序计算器（波特率/采样点/段配置，经典 CAN 与 CAN FD）

## 四、批次一 32 款插件规格

通用规格（全部插件遵守，详见 插件系统方案.md §八.3 准入清单）：
- 生命周期：`activate(context)` / `deactivate()`；证据行 `<名>插件已加载（…）` / `已停用`
- 命令：`<pluginId>.open` 注册 + `activationEvents: ["onCommand:<id>.open"]`
- UI：PyQt6，`sin.ui.create_window`，中文界面；关窗即停用
- 安全基线：**所有发送类操作默认停止**，仅用户点击按钮才发帧；订阅类插件激活即订阅（只读安全）
- 数据：实时插件走 `context.on_frame`（批量推送）；DBC 解析类内置纯 Python 解析器（不依赖宿主 RPC 逐帧解码，性能可控）；表格类支持 CSV 导出（utf-8-sig）

## 五、验收标准

1. **功能完备性**：每款插件按上表核心功能全量实现（非 demo），对标相应专业工具的主要工作流。
2. **生命周期合规**：通过 §八.3 准入清单（激活/命令/停用证据行、关窗停用、异常兜底）。
3. **安全基线**：发送类插件激活后零发送（E2E 舰队校验：激活期间 sendFrameRequested 无帧）。
4. **E2E 舰队**：`e2e_plugin_fleet` 对云端市场全部条目（新 32 + 已发布 5）执行 安装→激活→命令注册→命令分发→停用→卸载 全链路 PASS。
5. **云端发布**：market.json schema 2 条目齐全（图标/sha256/标签/关键词/说明），`http://sin.org.cn/market/market.json` 可下载安装。

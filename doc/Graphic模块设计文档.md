# Graphic 模块设计文档

> Graphic 是信号级分析的核心视图，对标 CANoe Graphics Window。
> 目标：多信号实时波形监控 + 游标精确测量 + 大数据流畅渲染。

## 二、当前架构

### 2.1 视图布局

```
┌─────────────────────────────────────────────┐
│ 工具栏: 缩放 | 适应 | 采样点 | 单卡尺 | 双卡尺 | 清除 | 暂停 | 导出 │
├──────────┬──────────────────────────────────┤
│ 信号列表  │  波形区 (多轴垂直堆叠)           │
│ 名称      │  ┌─ Signal A (独立 Y 轴) ──┐    │
│ 原始值    │  ├─ Signal B (独立 Y 轴) ──┤    │
│ 物理值    │  ├─ Signal C (独立 Y 轴) ──┤    │
│ 单位      │  └── 共享 X 轴 (时间) ──────┘    │
│ CAN ID   │     卡尺线 (可拖动)              │
│ [显隐]   │     当前时间指示线 (实时)        │
├──────────┴──────────────────────────────────┤
│ 卡尺信息: ΔT = 2.35s  ΔY = 15.3  f = 0.43Hz │
│ 状态栏: 信号数 / 点数 / 时间窗 / FPS         │
└─────────────────────────────────────────────┘
```

### 2.2 类设计（`src/ui/graphicview.h/cpp`）

```cpp
class GraphicView : public QWidget {
    struct Signal {            // 用户配置
        QString name; quint32 canId; bool extended;
        QColor color; DbcSignal dbcSig;
    };
    struct SignalData {        // 运行时数据
        Signal config;
        QCPGraph *graph;        // 曲线
        QCPAxis *yAxis;         // 独立 Y 轴
        QCPAxisRect *axisRect;  // 独立轴区
        QCPItemText *nameLabel; // 信号名叠加文本
        double dataMin, dataMax;
    };
    // 卡尺系统
    enum class CursorMode { None, Single, Double };
    QCPItemStraightLine *m_cursor1, *m_cursor2;
    int m_draggingCursor;       // 0=none 1/2=对应卡尺
    // 性能节流
    QTimer m_replotTimer;       // 50ms 批量 replot (20fps)
    QTimer m_valueTimer;        // 200ms 信号列表值刷新
    static constexpr int MAX_DISPLAY_POINTS = 50000; // 显示上限
};
```

### 2.3 多轴堆叠与联动机制

1. **每信号一个 `QCPAxisRect`**，垂直堆叠，共享底部 X 轴（时间）
2. **X 轴同步**：任一 rect 的 `xRangeChanged` → 中央处理函数统一更新其余 rect
3. **动态布局**：`layoutAxisRects()` 在信号增删/显隐切换时重算各 rect 高度与位置
4. **卡尺取值**：`valueAtTime()` 在相邻采样点间线性插值（`QCPGraph::data()->findBegin/findEnd` 高效查找）

### 2.4 数据流

```
CanSimulator/Player/Recorder 帧到达
    │ onFrame(frame)
    ▼
extractRaw(frame) → 按 DbcSignal 位定义提取原始值
    ▼
物理值 = raw × factor + offset
    ▼
graph->addData(timestamp, value)
    ▼ (50ms 定时批量)
m_replotTimer → replot()  ← 20fps 节流
    ▼ (200ms 定时)
m_valueTimer → updateSignalValues()  ← 信号列表刷新
```

## 三、待实现功能规划

### 3.1 视口降采样（✅ 已实施 G1 — `src/ui/graphic/downsample.h/cpp`）

**问题**：当前 `MAX_DISPLAY_POINTS = 50000` 硬截断，回放百万帧时：
- 截断丢失早期数据波形
- 50000 点全量重绘仍然卡顿

**方案**（借鉴 QCustomPlot 工程实践）：

```
原始数据 (百万点)
    │
    ▼ 视口范围 [t1, t2] × 每像素取 2 点
降采样 (min/max 分组抽稀)
    │  每像素列保留该列区间内的 min 和 max 两个点
    ▼
显示数据 (≈ 2 × 视口像素宽 ≈ 4000 点)
    │
    ▼ setData()
replot() — 恒定 O(视口宽度) 渲染成本
```

**实施要点**：
1. 新增 `DownsampleStrategy` 类：`minmax`（保轮廓，推荐）/ `avg` / `first` / `decimate`(每 N 取 1)
2. 视口变化（缩放/平移/时间窗切换）触发重算显示数据，原始数据不动
3. 降采样结果按视口缓存，视口未变复用
4. 环形缓冲区配合：原始数据存 `RingBuffer<QCPGraphData>`（容量可配，默认 100 万点/信号）
5. 拖动卡尺取值始终对原始数据插值（非降采样数据），保证测量精度

**收益**：百万点回放渲染成本从 O(n) 降至 O(视口宽)，60fps 恒定；波形轮廓无损。

**涉及文件**：
- 新增：`src/ui/graphic/downsample.h/cpp`
- 修改：`src/ui/graphicview.h/cpp`

### 3.2 信号数学运算（P1，对标 CANoe Math）

**目标**：由已有信号派生计算信号（如 `Torque = EngineRPM × 0.6 / 9549`）。

**设计**：

```
┌─ 添加计算信号 ────────────────────────────┐
│ 表达式: [EngineRPM * 0.6 / 9549         ] │
│         ↑ 内置表达式引擎复用 FilterEngine? │
│ 名称:   [输出轴扭矩 kW]                   │
│ 单位:   [kW]  颜色: [⬛ 自动]              │
└──────────────────────────────────────────┘
```

**实施要点**：
1. 计算信号类型 `Signal::Type = Dbc | Math`，Math 类型带表达式字符串
2. 表达式引擎：引入轻量解析器，变量名为已添加信号名
3. 数据生成：帧到达时先更新 DBC 信号，再对 Math 信号求值（依赖信号在同一帧或缓存最新值）
4. 计算信号同样支持卡尺插值、显隐、独立 Y 轴

**备选**：exprtk（已下载至 third_party，需评估）；或复用 `FilterEngine` 扩展算术求值。

**涉及文件**：
- 修改：`src/ui/graphicview.h/cpp`（Signal 结构 + 求值）
- 新增：`src/ui/mathsignaldialog.h/cpp`

### 3.3 多视图游标联动（✅ 已实施 G2 — `MainWindow::linkGraphicCursor`）

**目标**：多个 GraphicTab 的卡尺时间同步 — 移动任一视图卡尺，其他视图卡尺移动到同一时间点。

**实施要点**：
1. `GraphicView` 增加 `cursorMoved(double time)` 信号
2. `SplitEditorArea`（或 MainWindow）收集所有活动 GraphicView，收到 `cursorMoved` 后调用其他视图 `moveCursor(which, time)`（带阻塞标志避免回环）
3. 联动开关放工具栏（默认开）
4. 回放场景：回放当前位置线也参与联动（Player → 所有 GraphicView 同步当前时间）

**涉及文件**：
- 修改：`src/ui/graphicview.h/cpp`
- 修改：`src/ui/spliteditorarea.h/cpp` 或 `src/ui/mainwindow.cpp`

### 3.4 测量增强（P2）

- **区域统计**：双卡尺区间内 min/max/avg/σ/RMS 计算，结果表显示
- **信号对比模式**：两信号归一化叠加（各自 Y 轴自动缩放到 0-100%）对比趋势
- **注释标记**：在时间轴上添加文字注释点（测量事件记录）

### 3.5 数据管理增强（P2）

- **信号数据导出**：导出选中信号时间序列为 CSV（time, raw, physical）
- **数据缓存持久化**：Graphic 配置（信号列表、颜色、时间窗）保存到 `.openbusproj`，重开恢复
- **最大内存控制**：所有信号共享内存预算（如 500MB），超限自动降采样归档

## 四、技术选型

### 4.1 绘图库对比（结论：QCustomPlot ✅ 已采用）

| 库 | 协议 | 优势 | 短板 | 结论 |
|----|------|------|------|------|
| **QCustomPlot** | GPLv2 / 商业购买 | 轻量纯 Qt、多轴、游标、实时流、文档丰富、工业上位机大量在用 | 百万点需自实现降采样；无内置多通道同步游标 | ✅ **已采用**，已深度实现 |
| Qt Charts | GPL / Qt 商业 | 官方原生 | 性能弱、海量实时延迟高、定制难、商用需购 License | ❌ 已弃用（曾用后迁移） |
| Qwt | Qwt License (GPL 兼容) | 科学绘图、游标标尺优秀、实时流好 | UI 老旧、Qt6 适配坑、学习成本高 | ❌ |
| ImGui-Qt | MIT | 超高渲染性能 | 界面全手写、无法 Designer 拖拽 | ❌ 备选 |

### 4.2 QCustomPlot 关键使用约定

1. `QCPAxisRect` 每信号一个，垂直堆叠，手动 `setMinimumHeight()` 防重叠
2. X 轴范围同步用 `xRangeChanged` 信号汇聚到中央 handler
3. 卡尺用 `QCPItemStraightLine`（垂直线）+ 自管理拖拽状态（`m_draggingCursor`）
4. 插值用 `QCPGraph::data()->findBegin()/findEnd()` 高效区间查找
5. replot 必须节流（当前 50ms 定时批量，20fps）
6. `#include <functional>` 与 QMouseEvent 前置声明（扩展时的坑）

### 4.3 性能避坑

1. **降采样先行**：回放几十上百万帧直接渲染必然卡顿，任何新功能不得绕过降采样直接 `addData` 全量
2. **渲染与数据分离**：数据写入与 replot 分离（当前定时器机制保持）
3. **单线程渲染**：QCustomPlot 默认单线程渲染；实时高流速需数据缓存与 UI 线程分离（pending 队列 + 定时 flush，同 Trace Phase 2 模式）

### 8.3 主题联动架构（GraphicPalette）

**现状**：`graphicview.cpp` 中颜色全部硬编码（0x1E/0x2D/0x0C5D8F…），`ThemeManager::themeChanged` 无订阅。

**方案**：新增 GraphicPalette 结构，随主题切换重建，全视图一次性应用：

```cpp
// graphicview.h 内部
struct GraphicPalette {
    QColor canvas, grid, trackSep, axis, axisText;
    QColor timeLine, cursor1, cursor2, trackCursor;
    QColor nameTagBg, nameTagFg, nameTagBorder;
    static GraphicPalette canoeLight();   // 8.2.2 浅色基准
    static GraphicPalette canoeDark();    // 8.2.2 深色映射
};

// GraphicView
GraphicPalette m_palette;
void applyPalette();   // 重刷: 画布/网格/全部轴/曲线色板索引不重置/标签/QSS 工具栏与列表
```

实施要点：
1. 主题判定：取 `ThemeManager::currentTheme().windowBg` 亮度（>0.5 判浅色）→ 选 `canoeLight()/canoeDark()`；不依赖主题名字符串
2. 订阅 `ThemeManager::instance()->themeChanged` → `applyPalette()` + 单次 `replot()`
3. 工具栏/信号列表/QMenu 的 QSS 改为**模板函数动态拼接**（颜色从 `Theme` 取），删除全部硬编码色值；QMenu 直接用全局 QSS（移除局部样式表）
4. `styleAxisRect()` 改为读 `m_palette`，不再接收 QColor 参数染轴
5. 用户自定义信号颜色不受主题影响（仅自动分配色板换源）

### 8.4 布局与分栏实施要点（G7b）

#### 8.4.1 Y 轴三种显示方式（对标 CANoe，§九 #12-14）

工具栏新增 `Y轴:` 下拉，三态：

| 模式 | 行为 | 实现 |
|------|------|------|
| **分栏**（默认，现状） | 每信号独立 `QCPAxisRect` 垂直堆叠，各自完整 Y 轴 | 现有 `layoutAxisRects()` |
| **叠加·选中轴** | 全部曲线画入同一 axisRect；仅列表选中信号的 Y 轴显示刻度，其余轴隐藏刻度（选中哪个看哪个量纲） | 单 `m_overlayRect` + 每信号 `addAxis(atLeft)`；`graph->setKeyAxis/setValueAxis` 迁移；选中变化时切换 tickLabels |
| **叠加·全部轴** | 同上，但所有 Y 轴刻度并排显示 | 同上 + `axis->setOffset(i × 45)` 依次错开 |

实施要点：
1. 模式切换不重建 graph（`QCPAbstractPlottable::setKeyAxis/setValueAxis` 直接迁移，数据/缓存不动）
2. 叠加时信号名标签仍指向各自原 axisRect → 统一改指 `m_overlayRect`（左上堆叠显示，选中信号高亮）
3. 切回分栏时 graph 归位原 `sd.axisRect` 的轴；X 刻度/分隔线规则随模式重算
4. 卡尺/时间线/跟踪线的坐标轴引用在布局变化后重新 `setAxes` 到主轴（修复现状 item 默认轴悬空隐患）

### 8.6 缩放与平移交互（G7c，含缩放历史栈）

**交互矩阵**：

| 操作 | 行为 | 实现 |
|------|------|------|
| 滚轮 | 以鼠标为中心缩放（现状保留）；"Y锁定"开时只缩 X | 现有 `onWheel` + 锁定判断 |
| 左键拖框（框选模式开，默认开） | 拖出矩形放大：X 应用全部轨道，Y（若框高>5px）仅应用所在轨道 | 自绘 `QRubberBand`（不用内置 `srmZoom`，避免与多轨道 X 同步冲突）；松开时 `QSignalBlocker` 统一 setRange + `refreshDisplayData()` |
| 左键拖框高度 <5px | 仅缩放 X（CANoe 行为，便于水平放大） | 同上，跳过 Y |
| 左键拖（框选模式关） | 平移 X+Y（现状 `iRangeDrag`） | 现状 |
| 中键拖动 | 平移（任意模式） | `onMousePress`(MidButton) 记录起始范围 → move 差值平移 X 全轨 + Y 本轨 → release 结束 |
| 双击轨道空白 | 该轨道 Y 自适应 | `ensureMinMax` + margin（同 fitAll 单轨版） |
| 双击 Y 轴 | 轴设置对话框（min/max/自动） | QInputDialog 或轻量对话框 |

**缩放历史栈（Undo Zoom）**：

```cpp
struct ZoomState { QCPRange x; QList<QPair<QCPAxis*, QCPRange>> yRanges; };
QVector<ZoomState> m_zoomStack;   // 深度上限 50
bool pushZoomState();             // 与栈顶差异 > ε 才 push（ε=range*1e-6）
void undoZoom();                  // 恢复栈顶前一个，出栈
void undoAllZooms();              // 直接恢复栈底（全览）
```

- push 时机：框选缩放确认、中键平移结束、滚轮停止 500ms（防抖）、时间窗切换、fitAll 前
- 入口：工具栏 ↺ 按钮 / 右键菜单"撤销缩放·全部撤销" / `Ctrl+Z`
- 栈空时按钮禁用（状态同步）

**缩放轴三模式（对标 CANoe X/Y/XY 独立缩放，替代原单一“Y 锁定”）**：工具栏 `缩放轴:` 下拉（X / Y / XY，默认 XY）；滚轮/框选/键盘 ±缩放均受其约束（XOnly → 只改 X；YOnly → 只改 Y；XY → 都改）；fitAll 不受约束（语义即全适应）。

### 8.10 风险与备注

1. **白底黄时间线可见性**：纯黄 `#FFFF00` 在白底对比度中等（CANoe 即如此）；若实测不可接受，降饱和为 `#FFD900`，两主题统一 — 实施时对照实机截图定案
2. **框选缩放与卡尺拖动冲突**：`onMousePress` 先判卡尺/手柄命中（优先级高），未命中且框选模式开才启动橡皮筋；框选模式关时恢复 iRangeDrag 平移
3. **QRubberBand 与 QCustomPlot 坐标系**：橡皮筋绘制在 viewport 像素坐标，缩放换算用 `pixelToCoord`；松开后走统一同步函数（同现有 wheel 路径：blocker + `refreshDisplayData()` + replot）
4. **QCPItemText 富文本性能**：仅信号数 + 卡尺数个标签，开销可忽略；避免在 mouseMove 中 setPixmap/重设富文本（时间标签 setText 节流 200ms 与跟踪线共用）
5. **CANoe 版本差异**：色板与细节以 CANoe 12+ 默认浅色为准；实施时导出 1-2 张实机截图嵌入本文档 §8.2 作最终校准基准（可选）
6. **不改动范围**：G1 降采样/缓存机制、G2 联动信号、数据流、TimeTicker 格式、导出图片功能均保持不动，仅动视觉与交互层

### 9.2 CANoe Graphics 功能全景

#### 9.2.1 窗口与信号管理

| 功能 | CANoe 行为 |
|------|-----------|
| 打开方式 | Analysis → Graphics；Measurement Setup 插入 Graphics 模块 |
| 信号添加 | ① Symbol Explorer 拖拽信号 ② Trace 窗口拖拽信号 ③ 信号栏右键 Add Signals |
| 信号列表 | 左侧栏：信号名、当前值、Min、Max、单位、颜色 |
| 信号显隐 | 列表勾选 |
| 显示区（Track）分配 | 信号可分配到不同显示区域（Display Area），区域可增删 |
| 轨道顺序 | 信号可上移/下移调整显示顺序 |
| 界面瘦身 | 可隐藏左侧信号栏，扩大波形区 |
| Limit data | "限制数据到 n 秒"：测量结束时删除更早数据（控制内存） |
| 离线加载 | 拖入录制文件（.blf/.asc 等）直接绘图 |

#### 9.2.2 坐标轴系统（重点）

**X 轴（时间轴 / 键轴）**

| 能力 | CANoe 行为 |
|------|-----------|
| 统一时间轴 | 所有信号共用**唯一一条** X 时间轴 |
| 相对/绝对时间 | X 轴可显示相对测量开始时间（0 起）或绝对日期时间 |
| X 轴绑定信号 | X 轴可配置为**信号或变量**（XY 模式：X 不再是时间而是某信号值，画 X-Y 关系曲线） |
| Set time axis | 预设测量开始时的时间范围（时间窗） |
| X 轴独立缩放 | 仅缩放 X，Y 不动 |
| X 轴适应 | 一键回到全时间范围 |

**Y 轴（值轴）**

| 能力 | CANoe 行为 |
|------|-----------|
| 独立 Y 轴 | 每信号可拥有独立 Y 轴（量程差异巨大的信号如 12V 电压与 100kph 车速可同屏对比） |
| **三种 Y 轴显示方式** | ① **Show Y-Axis of Selected Signal**：仅显示当前选中信号的 Y 轴刻度（信号叠加在同一图，选中哪个看哪个刻度）<br>② **Show All Y-Axis**：所有信号的 Y 轴刻度并排显示<br>③ **Show Signals in Separate Diagrams**：分栏显示，每信号独立图表（各自完整轴） |
| Y 轴独立缩放 | 仅缩放 Y |
| XY 同时缩放 | X、Y 一起缩放（三种缩放轴模式与 9.2.3 配合） |
| Y 轴自适应 | 单信号 Fit（双击/右键） |
| 轴范围/格式配置 | 对话框设置 min/max、数值格式（十进制/十六进制/二进制、小数位）📷 |

**轴样式**

| 能力 | CANoe 行为 |
|------|-----------|
| 轴颜色/刻度文字 | 黑色轴线、黑色刻度文字（白底）；颜色只属于曲线 |
| 网格 | 浅灰实线网格，可开关 |
| 刻度密度 | 随窗口宽自适应 |

#### 9.2.3 缩放与平移

| 功能 | CANoe 行为 |
|------|-----------|
| 鼠标模式切换 | 测量 / 缩放 / 平移模式（模式选择按钮 + 拖拽行为配合） |
| Drag zoom（框选缩放） | 左键拖出矩形放大；**拖出扁平矩形（高度极小）= 仅缩放 X** |
| 滚轮缩放 | 以鼠标位置为中心 |
| 缩放轴选择 | **X 缩放 / Y 缩放 / XY 同时缩放** 三种模式独立可选 |
| Undo Zoom | 多级撤销缩放（缩放历史栈） |
| Undo All Zooms | 一步回到最初全览状态 |
| Fit（自适应） | 一键复原（多次调节后恢复全范围） |
| Fixed Scaling | 固定缩放（锁轴） |

#### 9.2.4 光标测量

| 功能 | CANoe 行为 |
|------|-----------|
| 单测量光标 | 单击启用；拖动光标线，左下角显示测量时间点，信号列表值随光标刷新 |
| 差分测量光标 | 双光标，拖动任一标尺测量 ΔT/ΔV/频率 |
| 取值方式 | 光标位置对曲线插值取值 |
| 光标手柄 | 光标顶部带手柄标记与时间标注 📷 |

#### 9.2.5 显示模式与样式

| 功能 | CANoe 行为 |
|------|-----------|
| **图形显示模式三态** | ① 全部彩色 ② 选中彩色（选中信号彩色，其余灰色）③ 选中显示（只显示选中信号，其余不显示） |
| 线型 | Line（折线）/ Step（阶梯）/ Points（仅点） |
| 图形加粗 | 线宽调整 |
| 信号颜色 | 信号栏右键自定义颜色；默认经典色板循环 |
| 采样点 | 可开关显示采样点 |

#### 9.2.6 数据与导出

| 功能 | CANoe 行为 |
|------|-----------|
| 图片导出 | 导出波形图 |
| 数据导出 | 信号数据导出 |
| 配置保存 | Graphics 配置随工程保存恢复 |
| 数学信号 | 表达式派生计算信号（Math） |

#### 9.2.7 操作方式汇总

| 操作 | 效果 |
|------|------|
| 左键单击（测量光标启用时） | 放置/选中光标 |
| 左键拖动光标 | 移动光标测量 |
| 左键拖框（缩放模式） | 框选放大（扁平框 = 仅 X） |
| 鼠标滚轮 | 以鼠标为中心缩放（受缩放轴模式约束） |
| 右键 | 上下文菜单（Fit / Undo Zoom / 显示方式 / 轴配置…） |
| 双击 Y 轴 | 轴配置对话框 📷 |
| 工具栏模式按钮 | 切换 X / Y / XY 缩放、测量/缩放鼠标模式 |

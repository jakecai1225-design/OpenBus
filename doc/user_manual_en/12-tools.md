# 12. Other tools

## 12.1 Watcher

**Tools > Watcher** (`Ctrl+Shift+W`)

- **Variable watch**: add signals from loaded DBCs; see current / raw / Min / Max.
- **Bus stats**: ID rate, period, jitter, and error summaries.
- Toolbar: **Add variable**, remove, clear, **Pause refresh**, **Reset stats**.

![Watcher](images/12-watcher.png)

## 12.2 Data Window

**Tools > Data Window** (`Ctrl+Shift+D`)

Shows selected signals / variables in a data-window style (good for gauge-like observation). Columns and refresh behavior follow the current UI.

## 12.3 I/O Graph

**Tools > I/O Graph** (`Ctrl+Shift+G`)

Plots bus load or TX/RX rate trends when enabled. Can run alongside measurement; do not confuse it with Graphic signal waveforms.

## 12.4 Color rules

**Tools > Color Rules…**

Configure Trace coloring rules matched top-down — useful for error frames, specific IDs, or directions.

## 12.5 Secondary side bar

With the Secondary Side Bar open:

- **Inspector** — selected frame details; add to Watch
- **Bookmarks** — bookmarks
- **Watch** — quick watch list

## 12.6 Settings

The bottom activity-bar **Settings** (gear) opens the settings page for general options; exact items follow the UI.

# 4. Project

## 4.1 Purpose

The **Project** workspace manages openbus projects: the open project tree, recent projects, and session entry points. A project remembers measurement layout, device, and analysis windows (exact persisted fields depend on the build).

## 4.2 Open the Project workspace

1. Click **Project** in the activity bar.
2. The side bar title is usually **EXPLORER**, with sections such as:
   - **Open Project**
   - **Recent**

![Project explorer](images/04-project-explorer.png)

## 4.3 New / open / save

| Action | Entry |
|--------|--------|
| New | Side bar **New Project**, or related menu items |
| Open | **File > Open Project…** (`Ctrl+Shift+O`) or side bar **Open Project** |
| Save | **File > Save Project** (`Ctrl+Shift+S`) |

## 4.4 Recent projects

- **Recent** on Welcome and in the Project side bar opens recent paths.
- Welcome also offers **Clear Recent**.

## 4.5 Open data files (not a project)

**File > Open File…** (`Ctrl+O`) opens log or DBC files. Formats vary by build; common ones:

- Logs: `.blf`, `.asc`, `.csv`, `.pcap`, `.trc`
- Databases: `.dbc`

**File > Import Log File…** (`Ctrl+I`) imports a log into Trace.

# 13. Keyboard shortcuts

Aligned with **Help > Keyboard Shortcuts** and the Settings shortcuts page.

| Action | Shortcut |
|--------|----------|
| Play / Pause | `Space` |
| Stop | `Ctrl+S` |
| Record | `Ctrl+R` |
| Open File | `Ctrl+O` |
| Open Project | `Ctrl+Shift+O` |
| Save Project | `Ctrl+Shift+S` |
| Import Log | `Ctrl+I` |
| Clear Trace | `Ctrl+L` |
| Toggle Side Bar | `Ctrl+B` |
| Toggle Panel | `Ctrl+J` |
| Command Center | `Ctrl+P` |
| Command Palette | `Ctrl+Shift+P` |
| Data Window | `Ctrl+Shift+D` |
| I/O Graph | `Ctrl+Shift+G` |
| Watcher | `Ctrl+Shift+W` |
| Split Right | `Ctrl+\` |
| Close Group | `Ctrl+W` |
| Exit | `Alt+F4` |

> Trace / Graphic may expose extra shortcuts (find, go to, …). Prefer each view’s context menu and tooltips.

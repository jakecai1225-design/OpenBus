# 11. Extensions and Marketplace

## 11.1 Purpose

**Extensions** discovers, installs, enables, and runs drivers and plugins. A compact side-bar list works together with the full **Marketplace** page.

## 11.2 Open the marketplace

1. Click **Extensions** in the activity bar.
2. Review **Installed** / **Running** in the side bar.
3. Open the full marketplace page to browse cards, search, and open details.

![Marketplace](images/11-market.png)

## 11.3 Search and install

1. Enter a model / vendor / keyword in the search box; press **Search** or Enter.
2. Click **Install** on a card, or open details and install there.
3. After install, the item appears under **Installed**; driver extensions may require a restart or device rescan.

## 11.4 Run plugins

- Installed plugins: double-click in the side bar, or use **Start** / **Stop** in details.
- The gear menu offers enable / disable / uninstall and similar actions.

## 11.5 Domain suites (brief)

The marketplace may ship domain windows (diagnostics, DBC Studio, protocol suites, and so on). They often have their own navigation and OUTPUT; follow the suite’s help or release notes. Launch from the marketplace or the side bar after install.

## 11.6 Notes

- Prefer trusted sources; do not force-install packages that fail hash checks.
- Hardware drivers often need vendor runtimes — install system components per the driver docs first.

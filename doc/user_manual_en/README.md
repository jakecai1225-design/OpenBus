## How to use this manual

1. **First time with the app** → start with [Getting started](02-getting-started.md).
2. **Understand the layout** → read [Workbench overview](03-workbench.md).
3. **Look up a feature** → open the matching chapter in the table below.
4. **Screenshots** → see [`images/`](../user_manual/images/README.md). Figures use `![…](images/xxx.png)`; if a PNG is missing from the repo, capture it using that folder’s notes.

## Conventions

- **UI copy**: the desktop UI is English. Control names in this manual match the software (for example **Device**, **Connect**).
- **Menu paths**: use `>`, as in **File > Open File…**.
- **Scope**: this manual describes current behavior. Domain suites in the marketplace follow the installed package.

# 13. 快捷键一览

与软件内 **Help > Keyboard Shortcuts** 及 Settings 中的快捷键页保持一致。

| 功能 | 快捷键 |
|------|--------|
| Play / Pause | `Space` |
| Stop | `Ctrl+S` |
| Record | `Ctrl+R` |
| Open File | `Ctrl+O` |
| Open Project | `Ctrl+Shift+O` |
| Save Project | `Ctrl+Shift+S` |
| Import Log | `Ctrl+I` |
| Clear Trace | `Ctrl+L` |
| Toggle Side Bar | `Ctrl+B` |
| Toggle Panel | `Ctrl+J` |
| Command Center | `Ctrl+P` |
| Command Palette | `Ctrl+Shift+P` |
| Data Window | `Ctrl+Shift+D` |
| I/O Graph | `Ctrl+Shift+G` |
| Watcher | `Ctrl+Shift+W` |
| Split Right | `Ctrl+\` |
| Close Group | `Ctrl+W` |
| Exit | `Alt+F4` |

> Trace / Graphic 内部可能还有额外快捷键（如查找、转到），请以各视图右键菜单与工具提示为准。

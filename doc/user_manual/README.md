## 本手册如何使用

1. **第一次接触软件** → 先读 [快速上手](02-getting-started.md)。
2. **想了解界面布局** → 读 [工作台总览](03-workbench.md)。
3. **按功能查用法** → 从下方「模块目录」进入对应章节。
4. **截图** → 见 [`images/`](images/README.md)。文中 `![…](images/xxx.png)` 为关键步骤示意；若仓库中尚未放入对应 PNG，请按该目录说明自行截取后补全。

## 约定说明

- **UI 文案**：界面以英文为主（与软件当前版本一致）。本手册中文说明旁会标注对应英文控件名，例如：活动栏 **Device**、按钮 **Connect**。
- **菜单路径**：用 `>` 表示层级，如 **File > Open File…**。
- **不改变功能**：本手册描述当前已实现行为；插件市场中的领域套件以实际安装包为准。

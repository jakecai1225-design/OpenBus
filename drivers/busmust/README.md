# BUSMUST USB-CAN(FD) driver

Supports Device Manager entry **BUSMUST USB-CAN(FD) Family**.

| Item | Value |
|------|--------|
| Lineage | Proprietary **BMAPI** (`bmcan`) |
| Runtime | `vendor/BMAPI64.dll` |
| Not | ZLG / PEAK / candle / gs_usb |

Scan devices after plugging in USB; channels appear under **BUSMUST USB-CAN(FD)**.

项目根目录由 CMakeLists.txt 作为顶层构建入口，启用 C++17、Qt6 AUTOMOC/AUTOUIC/AUTORCC，并通过 add_subdirectory(src) 聚合源码；.gitignore 排除构建产物、Qt 自动生成文件及 IDE 配置。README.md 与 README.en.md 提供中英文文档，描述 src/ 下的分层结构：core（CAN 帧、recorder/player/simulator、DBC 数据与管理）、models（Trace 表格模型与过滤代理）、ui（QMainWindow + QDockWidget 无边框窗口、可拆分编辑器区域、ActivityBar/SideBar、各功能面板）以及 utils。整体遵循「核心引擎 → 数据模型 → UI 界面」三层分离，UI 层通过 Qt Widgets 实现 Wireshark 风格的三栏 Trace 布局与可拖拽停靠面板。

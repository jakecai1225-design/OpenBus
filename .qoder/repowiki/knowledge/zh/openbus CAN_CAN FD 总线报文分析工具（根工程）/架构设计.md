工程采用三层静态库拆分架构：`src/core` 封装数据模型、设备驱动抽象（`candevice_zlg/peak/kvaser`）、DBC/ARXML 导入导出、BLF/ASC/CSV/PCAP/TRC 文件格式 I/O、过滤引擎、录制/回放/模拟器、项目与会话管理以及 Python 插件宿主；`src/models` 提供基于 `QAbstractTableModel` 的 Trace 数据模型与代理模型；`src/ui` 实现 VS Code 风格的无边框主窗口、可拆分编辑器、侧边栏面板、Trace/Graphic/Record/Playback 等标签页及工具集，并通过 `qcustomplot` 绘制波形。顶层 `CMakeLists.txt` 通过 `add_subdirectory(src)` 构建两个静态库 `openbus_core` 和 `openbus_ui`，最终链接为 `openbus` 可执行文件，并使用 PCH 加速编译。依赖方向严格自顶向下：UI → models → core → third_party（spdlog、nlohmann_json、pugixml、dbcppp、vector_blf、concurrentqueue）。驱动层通过 `driver/` 目录预置 ZLG/ZPSCANFD 等厂商 DLL，并在构建后自动拷贝至输出目录；Python 插件位于 `plugins/`，由 `core/plugin` 动态加载；SDK 暴露给外部脚本使用，位于 `sdk/sin/`。

- 核心功能按职责拆分为独立子目录（如 `core/canfileio/`、`core/file_import/`、`core/dbc/`、`core/plugin/`、`ui/tools/`），每个子模块以成对的 `.h/.cpp` 文件组织，并通过工厂或管理器类统一注册。
- 硬件设备访问通过 `candevice.h` 抽象基类 + 多实现（zlg、peak、kvaser）的多态模式，由 `candevicemanager` 根据配置动态选择具体驱动。
- 文件格式支持遵循“读取器/写入器”成对设计（如 `asc.cpp/h`、`blf.cpp/h`、`csv.cpp/h`、`pcap_reader.cpp/h`、`trc_reader.cpp/h`），并由 `canfileio_factory` 集中注册。
- UI 组件统一继承 `QWidget` 并以标签页/停靠面板形式嵌入 `MainWindow`，通过 `spliteditorarea` 管理可拆分编辑区与 Tab 生命周期。
- 构建系统通过 `target_precompile_headers` 为 `openbus_core` 和 `openbus_ui` 分别维护精简的公共头列表，避免全量 Qt 头重复编译。
- 资源文件通过 Qt Resource System (`resources/resources.qrc`) 集中管理 SVG 图标与 QSS 样式，主题切换由 `thememanager` 动态加载 `default.qss` / `theme.qss`。

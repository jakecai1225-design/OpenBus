- 核心能力以独立静态库组织：`openbus_core` 承载数据/引擎/IO，`openbus_ui` 承载界面组件，可执行目标仅链接 UI，使修改 UI 不触发 core 重编译。
- 硬件/文件格式/协议解析均采用接口+多实现模式：如 `candevice.h` 派生 `candevice_zlg/peak/kvaser`、`canfileio/canfileio_factory` 注册 BLF/ASC/CSV/PCAP/TRC 读写器、`file_import` 子模块统一导入器接口。
- Qt 元类型通过 `qRegisterMetaType` 在 `main.cpp` 集中注册（如 `CanFrame`），以便跨线程信号槽传递。
- 日志输出统一封装为 `OPENBUS_LOG_DEBUG/INFO/WARN/ERROR` 宏，调用 `logging::init()`/`shutdown()` 生命周期管理，替代原生 qDebug。
- 配置与状态通过单例管理器持久化：`AppConfig`、`SessionManager`、`ProjectManager`、`BookmarkManager`、`FilterPresetManager` 等均提供 `instance()->load()/save()` 接口。
- 插件以 Python 包形式组织，每个插件目录包含 `main.py` 入口与 `plugin.json` 描述文件，由 `sdk/sin/` 提供的 commands/frames/signals/workspace/ui/_transport 模块暴露宿主能力。

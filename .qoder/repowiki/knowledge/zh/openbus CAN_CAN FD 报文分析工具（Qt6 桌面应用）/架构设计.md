采用分层架构：`src/main.cpp` 初始化 QApplication、日志系统、AppConfig、SessionManager、ThemeManager 后启动 `MainWindow`；核心逻辑按目录划分为四层——`core/`（CAN 帧结构、设备抽象 `candevice*` + `candevicemanager`、录制/回放/模拟器、DBC 管理、过滤引擎、文件 I/O 工厂、项目/会话/书签/统计等）、`models/`（基于 QAbstractTableModel 的 `CanTraceModel` 及代理模型 `CanTraceProxyModel`、视口代理）、`ui/`（VS Code 风格无边框主窗口、Dock 面板、可拆分编辑器、各功能标签页如 Trace/Graphic/Record/Playback/SignalSend/DBC 详情等）、`utils/`（环形缓冲、无锁消息队列、SVG 图标）。构建产物拆分为三个 CMake 目标：`openbus_core`（静态库，不含 UI）、`openbus_ui`（静态库，依赖 core）、`openbus`（可执行，链接 ui），通过 PCH 加速编译。第三方依赖集中在 `third_party/`（spdlog、nlohmann/json、concurrentqueue、qcustomplot、vector_blf、dbcppp、pugixml、pugixml），由根 `CMakeLists.txt` 统一 include `third_party/Dependencies.cmake` 引入。硬件驱动以预编译 DLL 形式置于 `driver/`，构建后自动拷贝至 exe 同级目录，运行时通过 `zlgcan.dll` 等 SDK 访问 ZLG/Kvaser/PEAK 等设备。Python 插件体系位于 `plugins/`，每个插件含 `main.py` + `plugin.json`，由 `sdk/sin/` Python 包提供宿主 API（commands、frames、signals、workspace、ui、_transport）。UI 原型资源在 `UI/`（HTML+JS+CSS+partials），样式资源通过 `resources/resources.qrc` 打包进 Qt 资源系统。

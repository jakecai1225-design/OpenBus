- 核心能力按分层组织：core（数据/设备/文件/插件）、models（Qt 数据模型）、ui（界面组件），新增功能需明确归属对应目录
- 可插拔扩展采用 JSON 描述元数据（driver.json / plugin.json）配合 QPluginLoader 或 Python import 机制进行发现与加载
- 第三方依赖统一通过 third_party/Dependencies.cmake 集中声明，各子模块不单独 find_package
- 构建产物遵循固定输出约定：exe 与驱动插件均输出至 build/bin，driver SDK DLL 通过 POST_BUILD 复制至同级目录

- 每个厂商驱动以独立子目录组织，包含 CMakeLists.txt、driver.json、*_driver_plugin.{h,cpp} 四个文件。
- 插件类统一继承 QObject 与 CanDriverPlugin，并通过 Q_PLUGIN_METADATA 指定固定 IID "com.sin.openbus.CanDriverPlugin/1.0" 和对应 driver.json。
- driver.json 中 devices 数组用整型 type 字段标识设备型号，并标注 channels 与 canFd 能力。
- 厂商 SDK DLL 不随包静态链接，而是在运行时按 drivers/<id>/vendor → 应用目录 → PATH 的顺序动态查找加载。
- 插件头文件仅声明 driverId/displayName/version/deviceTypes/enumerateDevices/createDevice 五个虚函数，具体实现复用 src/core/candevice_*.cpp。

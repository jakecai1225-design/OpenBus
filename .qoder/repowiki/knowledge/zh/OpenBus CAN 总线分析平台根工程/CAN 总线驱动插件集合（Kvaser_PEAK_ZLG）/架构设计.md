模块顶层 CMakeLists.txt 通过 add_subdirectory 分别构建 zlg、peak、kvaser 三个子目标，每个子目录是一个独立的 Qt 动态库插件，输出到 build/bin/drivers/<id>/ 并与 driver_tool.py 打包成 .odp。

- 插件接口：每个子目录实现一个继承 QObject + CanDriverPlugin 的类（KvaserDriverPlugin/PeakDriverPlugin/ZlgDriverPlugin），通过 Q_PLUGIN_METADATA(IID "com.sin.openbus.CanDriverPlugin/1.0" FILE "driver.json") 声明元数据，由主程序通过 QPluginLoader 按 ABI 契约（同 Qt 版本、同编译器 MinGW 13.1 x64、C++17）加载。
- 实现复用：插件头仅暴露 driverId/displayName/version/deviceTypes/enumerateDevices/createDevice 等虚函数；具体设备枚举与创建逻辑复用 src/core/candevice_*.cpp（同一份源码编入本 target），厂商 DLL 在运行时按 drivers/<id>/vendor → 应用目录 → PATH 顺序动态加载。
- 设备清单：各子目录 driver.json 声明 id/name/version/vendor/busType/devices（type 编号、名称、通道数、canFd 标志）及 vendorSdk（DLL 名、是否随包分发、许可证说明）。
- 资源：drivers/market/assets/ 提供各驱动的 SVG 图标，供市场/商店展示使用。
- 依赖方向：插件仅依赖 src/core 暴露的 CanDriverPlugin 抽象与 ICanDevice 接口，不反向依赖主程序，保证 .odp 可独立分发。

根工程通过顶层 CMakeLists.txt 将 src（C++ 核心库 + Qt 界面）、drivers（Kvaser/PEAK/ZLG 的 .odp 驱动插件）纳入同一构建树；src 内部再拆分为 openbus_core（静态库：canframe/candevice/driverregistry/dbc/fileio/plugin 等）、openbus_ui（静态库：Qt 界面组件）和 openbus 可执行目标，形成 core → ui → exe 的单向依赖链。运行时由 main.cpp 启动 UI，UI 通过 core::driver::DriverRegistry + QPluginLoader 动态加载 drivers/*/*.odp 中的硬件驱动，并通过 core::plugin::PluginManager 加载 plugins/* 下的 Python 扩展；driver/ 目录下的 ZLG SDK DLL 在 POST_BUILD 阶段被复制到输出目录供 exe 直接调用。SDK 层 sdk/sin 提供 Python 侧 API，plugins 与 scripts 共享该 SDK 与 resources.qrc 资源体系，构成“C++ 内核 + Qt 界面 + Python 插件 + 可插拔驱动”的统一架构。

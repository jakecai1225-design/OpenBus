- 核心数据结构（如 CanFrame）通过 QDataStream 友元运算符实现序列化/反序列化，用于录制文件和跨模块传递。
- 跨线程数据传递统一通过 FrameQueue 的 enqueue/tryDequeueBulk 接口，禁止直接共享容器。
- UI 组件采用单例或全局管理器模式（ThemeManager、AppConfig、DbcManager）通过 instance() 获取，避免全局指针散落。
- CMake 中通过 set(SRC_CORE|SRC_MODELS|SRC_UI ...) 显式列出源文件，配合 target_precompile_headers 按层裁剪预编译头以减少编译时间。
- Qt 信号槽命名遵循 onXxx() 前缀约定（如 onRecord、onPlay、onFrameReceived），并在 MainWindow 集中声明 private slots。
- 头文件中使用前置类声明（class TraceTab; class Recorder; 等）减少 include 依赖，仅在 .cpp 中包含完整头。

模块采用清晰的四层分层结构，由 CMakeLists.txt 通过 SRC_CORE / SRC_MODELS / SRC_UI / SRC_UTILS 四组变量组织：
- core 层：纯业务逻辑，定义核心数据结构 CanFrame（支持经典帧与 CAN FD，含 QDataStream 序列化）以及 Recorder（.sin 二进制录制）、Player（按时间戳回放 .sin）、CanSimulator（模拟报文注入）、DbcManager（DBC 文件解析）。
- models 层：Qt Model/View 适配，CanTraceModel 继承 QAbstractTableModel 管理帧序列，CanFilterProxyModel 提供过滤代理。
- ui 层：以 MainWindow 为根，使用 QMainWindow + QDockWidget 构建可停靠布局，包含 ActivityBar、SideBar、BottomPanel、RightPanel 等面板，以及 TraceTab、PlaybackTab、RecordTab、SignalSendTab、DbcDetailTab 等功能页签；TraceView/GraphicView 负责数据可视化。
- utils 层：canutils 提供跨层工具函数。
依赖方向严格单向：ui → models/core/utils，models → core，core 不依赖任何 UI。main.cpp 仅注册 CanFrame 元类型并启动 ThemeManager 与 MainWindow。

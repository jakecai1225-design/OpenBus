项目采用 CMake 分层构建，顶层 `CMakeLists.txt` 查找 Qt6 并引入 `third_party/Dependencies.cmake` 管理第三方依赖；`src/CMakeLists.txt` 将代码拆分为三个目标：`sin_core`（静态库，含 core/models/utils 三层，暴露公共头给 UI）、`sin_ui`（静态库，仅依赖 sin_core 和 Qt Widgets，qcustomplot 通过 PRIVATE 链接隔离）、最终可执行目标 `sin`（入口 `src/main.cpp`）。核心层按职责划分为：`core/canfileio/` 实现 BLF/ASC/CSV/PCAP/TRC 等格式的统一 I/O 抽象（工厂模式 + 具体 reader）；`core/file_import/` 以统一 `FileImporter` 接口封装 ASC/BLF/CSV 导入；`core/dbc/` 封装 dbcppp 完成 DBC 读写；`core/candevice*` 定义 `ICanDevice` 抽象并通过 `CanDeviceManager` 动态加载 ZLG SDK，后续可扩展 PEAK/SocketCAN 等后端。UI 层以 `MainWindow` 为根，使用 QDockWidget/QSplitter 实现无边框 VS Code 布局，`panels/`、`tools/` 子目录分别承载侧边栏面板与独立工具视图。数据模型层 `models/` 提供 `CanTraceModel` + `CanFilterProxyModel` 作为 Trace 表格的虚拟 Model。线程模型上，模拟器/回放/采集通过无锁队列 `utils/message_queue.h`（基于 moodycamel::concurrentqueue）与主 UI 解耦。构建期通过 `target_precompile_headers` 在 sin_core/sin_ui 分别预编译精简/完整 Qt 头以提升增量编译速度。

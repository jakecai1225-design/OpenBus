- 核心能力通过纯虚基类 + 工厂/管理器扩展：如 `canfileio` 的 `CanFileIO` 接口配合 `CanFileIOFactory` 注册不同格式 reader，`file_import` 的 `FileImporter` 统一 ASC/BLF/CSV 导入入口。
- 模块间依赖方向严格自顶向下：UI (`ui/`) → Models (`models/`) → Core (`core/`) → Utils (`utils/`)，UI 不直接包含底层硬件或文件格式头，仅通过 sin_core 暴露的公共头访问。
- 第三方依赖通过 `third_party/Dependencies.cmake` 以 INTERFACE IMPORTED 或 add_subdirectory 方式引入，并在 `src/CMakeLists.txt` 中用 `if(EXISTS ...)` 条件判断是否启用，保证缺失第三方时仍可部分构建。
- 使用 CMake `target_precompile_headers` 为 sin_core 和 sin_ui 分别维护精简/完整的 Qt 头清单，避免全量重编译。
- 跨线程数据传递统一通过 `Q_DECLARE_METYPE` 注册的 `CanFrame` 结构体配合 Qt 信号槽或 `MessageQueue` 无锁队列，禁止在主线程之外直接操作 UI。
- UI 组件遵循单例/管理器模式组织全局状态：`ThemeManager`、`AppConfig`、`DbcManager`、`CanDeviceManager` 等均以 `instance()` 单例形式提供全局访问。

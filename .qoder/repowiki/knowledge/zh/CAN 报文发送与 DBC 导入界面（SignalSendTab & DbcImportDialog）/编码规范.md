- 信号级编辑器通过遍历 `DbcMessage::signalList` 动态创建控件：有 valueTable 的枚举信号使用 `QComboBox`，数值信号使用带范围/步长/小数位数的 `QDoubleSpinBox`，统一存入 `m_signalWidgets` 列表以便后续读写。
- Raw 数据与信号值的双向同步采用 `m_updatingSignals` 标志位配合 `QSignalBlocker` 阻断循环触发，确保修改信号控件不会再次触发 `editingFinished` 导致死循环。
- 发送列表每行操作按钮通过 `createOpWidget()` 工厂方法构造，并使用 `findRowOfButton()` 在回调中根据父 widget 反查所在行号，避免为每个按钮维护行索引。
- CAN ID 与 Hex 数据的格式化为静态辅助函数（`formatIdHex`、`parseHexData`、`formatDataHex`），在多处添加行、导入、编辑路径中统一复用。
- DbcImportDialog 使用 `Qt::UserRole+1/+2` 自定义角色（`RoleCanId`、`RoleIsMsg`）在 `QTreeWidgetItem` 上存储 CAN ID 与节点类型，用于筛选后收集选中 Message 的 ID。

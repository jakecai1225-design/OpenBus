模块由两个 Qt Widget 组成：`SignalSendTab`（`src/ui/signalsendtab.*`）作为中央标签页，使用 `QSplitter` 将上半部分的 `QTableWidget`（发送列表，含勾选、ID、DLC、Hex 数据、周期、次数、状态、操作列）与下半部分编辑区分开；下半部分包含 Raw 帧编辑行（ID/DLC/数据(Hex)/周期/次数 + 添加到列表/发送单帧按钮）和基于 DBC 的信号级编辑器区域（动态生成 `QDoubleSpinBox` 数值控件与 `QComboBox` 枚举控件）。上下通过 `onSendTableRowChanged` → `loadRowToEditor` 联动，信号值变化经 `updateDataFromSignals` / `updateDataFromSignals` 双向同步到 Hex 数据区并回写选中行。`DbcImportDialog`（`src/ui/dbcimportdialog.*`）是模态对话框，用 `QTreeWidget` 展示 DBC 文件→Message→Signal 层级，支持按 CAN ID 或信号名实时过滤树节点，并通过 `selectedCanIds()` 返回选中的 Message ID 列表供 `SignalSendTab` 追加到发送列表。两者均依赖 `core/dbcmanager.h` 提供的 `DbcManager` 与 `DbcMessage`/`DbcSignal` 数据结构，不直接访问底层硬件，发送动作通过 `sendAllRequested` / `sendSingleRequested` / `sendRowRequested` 等信号向上层派发。

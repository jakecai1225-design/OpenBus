模块由两个 Qt Widget 组成：`SignalSendTab`（`src/ui/signalsendtab.{h,cpp}`）作为中央区域的主控件，使用 `QSplitter` 将界面分为上下两部分——上半部是 10 列的 `QTableWidget`（含勾选、序号、ID、名称、DLC、Hex 数据、周期、次数、状态、操作按钮），下半部是 `QGroupBox` 编辑区，包含 Raw 帧输入（ID/DLC/数据/周期/次数）和基于 DBC 动态生成的信号编辑器（`QScrollArea` + `QVBoxLayout`）。通过 `setDbcManager(DbcManager*)` 注入依赖，利用 `DbcManager::findMessage(id)` 解析消息并调用 `DbcSignal::encode/decode/rawDecode` 在信号值与 Hex 字节间双向转换；上下联动通过 `m_selectedRow` 与 `loadRowToEditor` 实现表格选中行与底部编辑器的同步。`DbcImportDialog`（`src/ui/dbcimportdialog.{h,cpp}`）作为独立弹出窗口，封装 `QTreeWidget` 树形展示 DBC 报文并提供按 CAN ID / 信号名的搜索过滤，用户确认后返回选中的 CAN ID 列表供 `SignalSendTab` 批量追加到发送表。模块通过 signals（`sendAllRequested`/`stopAllRequested`/`sendSingleRequested`/`sendRowRequested`/`stopRowRequested`）向上层暴露发送动作，保持 UI 与底层设备驱动解耦。

- 所有可插拔组件（硬件驱动、Python 功能插件）均通过 JSON 描述元数据（driver.json / plugin.json）并由宿主在运行时动态发现与加载。
- C++ 子模块遵循 `src/core/<domain>/` 命名空间划分，每个领域自包含头文件与源文件，并通过 `core/module/` 注册到全局模块管理器。
- Python 插件统一采用 `main.py` 入口 + `plugin.json` 声明 + `__pycache__` 缓存的结构，并通过 `sdk/sin` 提供的命令/frames/dbc 接口与宿主通信。
- 构建产物按职责分层：`build-rel/src/` 生成静态库 `.a`，`build-rel/bin/` 放置可执行与动态库，`build-rel/drivers/` 放置各厂商驱动插件，便于独立部署。

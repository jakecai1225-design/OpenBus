项目以 `src/main.cpp` 启动 Qt 应用，核心能力按领域拆分为 `src/core/` 下的独立子系统（driver、protocol、dbc、canfileio、plugin、marketmodel 等），UI 层在 `src/ui/` 中通过模块化页面（tracemodule、graphicmodule、flowmodule、transceivemodule、marketmodule 等）组合呈现；硬件抽象由 `drivers/` 下各厂商驱动插件（candle/kvaser/peak/slcan/zlg）统一实现并动态加载，运行时产物位于 `build-rel/bin/drivers/<vendor>/`；功能扩展通过 `plugins/` 目录下的 Python 插件（每个含 main.py + plugin.json）经 SDK `sdk/sin/` 暴露给宿主进程，由 `core/plugin/` 和 `core/marketmodel/` 负责发现、加载与生命周期管理；构建系统使用顶层 CMakeLists.txt 聚合 src、drivers、tests、vector_blf 等子工程，最终打包为 `openbus.exe` 及依赖 DLL/QML 资源。

- 核心逻辑与 UI 严格分离：core/models/utils 不依赖任何 Qt Widget，仅通过 sin_core 静态库暴露公共头供 ui 层使用
- 所有 Qt 元类型（如 CanFrame）在 main.cpp 中通过 qRegisterMetaType 注册，确保跨线程信号槽传递
- 第三方库统一放在 third_party/ 目录并通过 Dependencies.cmake 引入，sin_core 用 PUBLIC include_directories 向下游透传头文件路径
- UI 组件采用 Qt 标准命名：类名 PascalCase，源文件 .h/.cpp 成对，MOC/UIC/RCC 由 CMake AUTOMOC/AUTOUIC/AUTORCC 自动处理
- 日志通过 logging::init()/shutdown() 生命周期管理，spdlog 输出到文件与控制台双通道
- 配置文件通过 AppConfig 单例加载，主题通过 ThemeManager 单例应用，全局状态集中管理

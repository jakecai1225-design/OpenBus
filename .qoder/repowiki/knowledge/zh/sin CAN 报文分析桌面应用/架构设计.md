项目采用分层静态库架构：`src/core`（CAN 帧、DBC、播放器/录制器、过滤器、配置）与 `src/models`（Qt 数据模型）、`src/utils`（工具）合并为 `sin_core` 静态库；`src/ui` 所有界面组件构成 `sin_ui` 静态库并 PUBLIC 依赖 sin_core；顶层 `sin.exe` 仅链接 sin_ui，main.cpp 中完成 QApplication 初始化、日志系统启动、AppConfig 加载、ThemeManager 主题应用后创建 MainWindow。
- 核心层通过 `qRegisterMetaType<CanFrame>` 暴露跨线程信号槽的数据类型，core 与 ui 之间以 CanFrame 及 DBC 数据结构为契约。
- 第三方依赖（spdlog、nlohmann_json、concurrentqueue、qcustomplot、dbcppp）集中在 `third_party/`，由 `third_party/Dependencies.cmake` 统一引入，sin_core 通过 PUBLIC include_directories 向 sin_ui 透出头文件路径。
- UI 层按功能拆分为 Tab 页（TraceView、GraphicView、PlaybackTab、RecordTab、SignalSendTab、DbcDetailTab、UdsView、MeasurementSetupView 等），由 MainWindow 和 SplitEditorArea 组织布局。
- 构建使用 Qt6 AUTOMOC/AUTOUIC/AUTORCC，Windows 下可选 LLD 加速链接，PCH 分别针对 core（精简 Qt 头）和 ui（完整 Widget 头）优化编译速度。

# SignalSendTab 采用上下分栏布局与双向数据同步

_来源：d0ac9ba → 6257dee 提交周期内记录的编码计划——内容为规划时意图，实现可能滞后或有出入。_

**状态：** accepted

## 背景
原有的 SignalSendTab 发送页面功能单一，用户需要频繁在 DBC 文件导入、帧编辑和批量发送之间切换，操作路径长且容易出错。需要重构界面以支持更直观的 CAN 帧编辑流程。

## 决策驱动
- 用户体验：减少操作步骤
- 数据一致性：表格与编辑器实时同步
- 可维护性：分离导入逻辑到独立对话框

## 备选方案
- **单页内嵌式布局（最终选择）** — 优点：所有操作在同一页面完成，无需跳转；表格行点击即可编辑对应帧；支持枚举信号的下拉选择；缺点：页面内容较多，需要合理分区
- **多标签页布局** _（已否决）_ — 优点：功能模块清晰分离；缺点：用户需要在标签间切换，增加操作步骤；无法同时查看列表和编辑细节
- **主从视图模式** _（已否决）_ — 优点：符合传统 IDE 设计模式；缺点：学习成本较高；对于简单的 CAN 帧编辑场景过于复杂

## 决策
采用上下分栏布局：上半部分为发送帧列表（Send Table），下半部分为 Raw 数据编辑区和信号编辑器。通过 onSendTableRowChanged() 实现表格行选择与底部编辑器的双向同步，当选中行变化时自动填充编辑器，编辑器修改后更新对应行数据。

## 影响
1) 新增 DbcImportDialog 独立处理 DBC 文件导入，通过 selectedCanIds() 返回选中的 CAN ID 列表；2) 信号编辑器根据 valueTable 动态创建 QComboBox（枚举信号）或 QDoubleSpinBox（数值信号）；3) 顶部工具栏简化为列表级操作（发送/停止/清空），将 DBC 导入移到底部编辑区；4) 增加了 m_selectedRow 状态管理当前选中行，onAddToList() 支持更新已有行而非重复添加。

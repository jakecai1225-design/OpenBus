工程以 CMake 为构建系统，按「拆分应用实施方案」将代码拆分为多个共享库：`openbus_data`（core/models/utils + thememanager，承载所有单例如 DbcManager/PluginManager/AppConfig）、`openbus_market`（插件市场页）、`openbus_transceive`（发送/回放/离线分析/录制四页面）、`openbus_dbc`（DBC 详情页与信号清单）、`openbus_flow`（测量流程与设备连接）、`openbus_trace`（Wireshark 风格 Trace 视图）、`openbus_graphic`（qcustomplot 波形图与 DataWindow），以及静态库 `openbus_ui`（壳 UI）和最终可执行目标 `openbus`。模块间通过 `core/module/imodule.h` 定义的统一接口与 `ModuleRegistry` 注册表解耦，每个业务 DLL 暴露一个 C 工厂函数（如 `openbus_createTraceModule()`）供壳动态加载。驱动子系统位于 `drivers/<id>/`，每个厂商实现 `Candriverplugin` 并通过 `driverregistry` 热加载；内置 ZLG SDK 二进制位于 `driver/kerneldlls/`。插件生态由 `plugins/` 下的 Python 包（含 `plugin.json` 清单与 `main.py` 入口）构成，通过 `sdk/sin/` 提供的 Python SDK 与宿主通信，并由 `scripts/plugin_tool.py` / `make_market.py` / `driver_tool.py` 提供打包与市场索引生成。UI 原型独立存放于 `UI/`（HTML+JS+CSS 片段）。测试覆盖核心逻辑（`tests/` 中的 Qt Test）与 E2E 场景（`scripts/e2e_*.cpp`）。

- 每个测试文件对应一个业务域（B1-B7/C），类名以 `TestXxx` 命名并在 `private slots:` 中声明用例方法，断言使用 `QVERIFY`/`QCOMPARE`/`QSKIP`。
- 测试数据路径通过 `SIN_SOURCE_DIR` 编译宏拼接 `test/resources/` 下的样本文件，避免硬编码绝对路径。
- 对真实样本文件只做自洽性不变量断言（如 dlc/data.size() 一致、ID 范围、时间戳单调），对导出-重导入闭环才做逐字段精确比对。
- UI 测试通过 `initTestCase`/`cleanupTestCase` 成对初始化/还原全局状态（如 DriverRegistry 禁用 zlg 并备份 restored disabled.json），保证测试间隔离。
- L2 UI 测试通过 `findChildren<QWidget*>()` + `metaObject()->className()` 按类型查找控件，不直接 include 具体视图头，降低耦合。

采用 CMake 集中管理 8 个独立可执行测试进程（test_canfileio / test_filterengine / test_tracecore / test_dbc / test_sim_rec_play / test_market_driver / test_project / test_ui_offscreen），通过 `openbus_add_test` 函数统一链接 `openbus_data` 与 `Qt6::Test`，每个进程隔离 core 层单例状态（DbcManager/PluginManager 等）。L1 数据层测试使用 `QTEST_GUILESS_MAIN` 以 `QCoreApplication` 运行；L2 UI 层 `test_ui_offscreen` 单独用 `qt_add_executable` 链接壳 UI 静态库与 4 个业务模块 DLL（openbus_ui/openbus_market/openbus_transceive/openbus_dbc/openbus_flow），并通过 `QT_QPA_PLATFORM=offscreen` 环境变量实现无头运行。所有测试通过 `ctest` 注册并以 `build/bin` 为工作目录，依赖 `SIN_SOURCE_DIR` 宏定位 `test/resources/` 下的样本数据。顶层 `doc/测试验收方案.md` 定义三层金字塔策略（L1 核心集成 → L2 offscreen UI → L3 人工抽查），`doc/测试报告.md` 记录执行结果。

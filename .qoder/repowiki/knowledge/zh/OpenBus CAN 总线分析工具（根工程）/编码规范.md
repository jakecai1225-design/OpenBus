- 新增硬件驱动以独立 `drivers/<vendor>/` 子目录形式实现，包含 `driver.json` 元数据与 `*_driver_plugin.cpp` 入口，由 DriverRegistry 自动发现注册。
- 新增功能扩展以 Python 插件形式放入 `plugins/<name>/`，提供 `plugin.json` 描述与 `main.py` 入口，通过 PluginHost 在运行时加载。
- UI 界面采用模块化拆分：每个业务域对应 `src/ui/*module.cpp`，通过信号槽与 `src/core/` 中的 Manager 交互，不直接耦合底层设备。
- 资源（图标、样式、文档）集中放置于 `resources/`，通过 Qt Resource System (`resources.qrc`) 统一引用。
- 第三方库通过 `third_party/` 与 `third_party/Dependencies.cmake` 集中管理，子模块以 FetchContent 或静态链接方式集成。

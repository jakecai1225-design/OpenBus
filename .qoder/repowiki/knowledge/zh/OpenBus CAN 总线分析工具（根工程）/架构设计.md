根目录按职责分层组织：`src/` 提供 Qt 应用核心（`core/` 设备与数据管线、`ui/` 界面模块、`models/` Trace 模型、`utils/` 通用工具），`drivers/` 以独立 CMake 子项目形式实现各硬件厂商驱动并通过 `core/driver/` 的 DriverRegistry 动态加载；`plugins/` 为 Python 插件，由 `core/plugin/pluginhost` 在运行时发现并启动；`sdk/sin/` 暴露给插件使用的 Python SDK；`resources/` 集中图标与 QSS 主题供 UI 层共享；`third_party/` 通过 `Dependencies.cmake` 引入 dbcppp、spdlog、qcustomplot 等三方库；顶层 `CMakeLists.txt` 将 core、drivers、tests 组装为单一可执行文件，`scripts/` 提供构建、市场打包与插件工具脚本；`test/` 与 `tests/` 分别存放验收截图与 Qt Test 用例，覆盖核心能力。

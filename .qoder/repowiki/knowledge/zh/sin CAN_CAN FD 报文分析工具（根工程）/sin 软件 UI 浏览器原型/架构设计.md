采用「单入口 + 动态 partial 注入」的无框架原型架构：
- 入口 `ui-prototype.html` 仅定义占位容器（`#partial-*`）和全局样式引用；所有功能区域以独立 HTML 片段存放在 `partials/` 目录（menubar、left-dock、center-area、right-dock、bottom-dock、dialogs、overlays、scenario-bar）。
- `js/ui-loader.js` 通过 `fetch` 并发加载全部 partial，完成后调用全局 `initPage()` 钩子初始化交互逻辑。
- `js/ui-prototype.js` 集中管理所有页面状态切换：菜单下拉、左侧 ActivityBar/SideBar 面板切换、中央标签页切换、右侧 Dock 标签页切换、底部 Dock 标签页切换、场景切换器（`setScenario`）、右键菜单、拆分视图（`showSplitView`）以及 AI 对话模拟。
- `css/ui-prototype.css` 按区域划分样式块（窗口、菜单栏、左侧栏、中央、Graphic、DBC、信号发送/录制、拆分视图、右侧栏、底部 Dock），使用 CSS 类名控制 active/checked/unchecked 等状态。
- `ui-layout.md` 作为唯一权威布局规范，描述各面板尺寸、颜色主题、字体、交互行为，是后续 Qt 实现的对照文档。
依赖方向单向：HTML → loader → partials → prototype.js（仅操作 DOM），无模块系统或构建步骤，直接双击 html 即可在浏览器预览。

- 每个 UI 区域以独立的 HTML partial 文件存放，并在 `ui-loader.js` 的 partials 数组中以 `{id, url}` 形式声明，由 loader 统一注入对应占位容器。
- 页面状态切换统一通过添加/移除 CSS 类（`.active`、`.open`、`.checked`、`.unchecked`）实现，而非直接操作 display/visibility。
- 所有交互函数挂载到全局命名空间（如 `switchPanel`、`switchCenterTab`、`setScenario`、`initPage`），由 loader 在 partial 加载完成后回调 `initPage()` 触发初始化。
- 中央标签页与左侧 ActivityBar 通过 `tabPanelMap` 映射表进行双向联动，切换标签页时自动同步左侧面板高亮。
- CSS 按区域分块组织（窗口、菜单栏、左侧栏、中央、Graphic、DBC、拆分视图、右侧栏、底部 Dock），并使用 BEM 风格类名（如 `.menu-item`、`.ctab`、`.dock-pane`）。
- 场景切换通过 `setScenario(name)` 单一入口分发，内部组合调用 `switchPanel` / `switchCenterTab` / `switchRightTab` / `switchBottomTab` 完成多区域联动。

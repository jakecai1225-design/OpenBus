根 `CMakeLists.txt` 通过 `add_subdirectory(src|drivers|tests)` 把三大子域聚合到单一构建树：`src/` 提供核心运行时（设备管理、DBC、协议解析、UI、Shell RPC），`drivers/` 按厂商（zlg/kvaser/candle/peak/slcan）产出独立 `.odp` 驱动插件并输出到 `build/bin/drivers/<id>/`，`tests/` 使用 Qt Test 对核心逻辑做集成测试；Python 侧的 `plugins/` 目录由 `scripts/make_market.py`、`plugin_tool.py` 等脚本在构建后扫描 `plugin.json` 打包进市场索引，不进入 CMake 树。运行时通过 `core/plugin/pluginmanager` 动态加载 C++ 插件、通过 `core/shell/http_rpc_server` 暴露 HTTP-RPC 供 Python SDK (`sdk/sin`) 调用，形成 C++ 宿主 + Python 插件的双语言架构。顶层 `installer/openbus.iss` 与 `scripts/package.py` 负责把 `bin/`、`drivers/`、`plugins/`、`resources/` 及第三方库统一打包为安装包。

- 业务模块通过 `IBusinessModule` 接口 + C 工厂函数（`openbus_createXxxModule`）跨 DLL 边界导出，模块内部类不对外暴露，仅依赖 Qt 基础类型与前向声明的数据层指针。
- 驱动插件统一实现 `CanDriverPlugin` 接口并以 `Q_PLUGIN_METADATA` 注册，通过 `DriverRegistry` 按 `driver.json` 中的 `devices[].type` 枚举与创建设备实例。
- Python 插件遵循 `activate(context)` / `deactivate()` 生命周期约定，通过 `sin` SDK 提供的 `frames.send`、`ui.create_window`、`output.append` 等 API 与宿主交互，UI 使用 PyQt6 构造独立窗口。
- 核心数据结构（如 `CanFrame`）在 `main.cpp` 中通过 `qRegisterMetaType` 注册元类型，以便在信号/槽跨线程传递。
- 日志输出统一通过 `OPENBUS_LOG_DEBUG/INFO/WARN/ERROR` 宏封装 spdlog，并在 `logging::init()` / `shutdown()` 中集中管理生命周期。
- UI 样式通过 `resources/styles/default.qss` 与 `ThemeManager` 切换主题，图标统一放在 `resources/icons/*.svg` 并由 qrc 资源系统管理。

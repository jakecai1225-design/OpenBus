项目采用「壳进程 + 业务 DLL + 原生驱动插件 + Python 插件」的分层架构：
- 入口 `src/main.cpp` 初始化 QApplication、日志、AppConfig/SessionManager，并通过 `ModuleRegistry` 以 C 工厂函数（`openbus_createMarketModule` 等）动态加载 `openbus_market.dll` / `openbus_transceive.dll` / `openbus_dbc.dll` / `openbus_flow.dll`，模块间通过 `IBusinessModule` 接口与 `ShellContext` 解耦。
- 核心逻辑集中在 `src/core/`：数据模型（`canframe.h`）、设备抽象（`candevicemanager` + `candevice_*` 多厂商实现）、文件 I/O（`canfileio/` 支持 BLF/ASC/CSV/PCAP/TRC）、DBC 管理（`dbcmanager` + dbcppp）、过滤引擎（自研递归下降表达式解析）、录制/回放/模拟器、工程与会话管理。
- UI 层 `src/ui/` 基于 QMainWindow + QDockWidget + QSplitter 实现 VS Code 风格无边框窗口、可拆分编辑器区、ActivityBar/SideBar/BottomPanel 面板；Trace/Graphic/Flow/Market 等作为独立模块标签页。
- 原生驱动插件位于 `drivers/<id>/`（zlg/peak/kvaser/candle/slcan），通过 `QPluginLoader` 按 `CanDriverPlugin` 接口（`Q_DECLARE_INTERFACE`）热加载，每个驱动包含 `driver.json` 描述设备类型，由 `DriverRegistry` 统一管理枚举、安装、禁用与卸载。
- Python 插件位于 `plugins/<name>/`（blf-converter/bus-statistics/canopen-explorer/dbc-tool/uds-diagnostic），通过 `PluginHost`（`src/core/plugin/`）以 `QProcess` 启动 `scripts/sin_host.py`，使用 newline-delimited JSON-RPC 与宿主通信；插件通过 `sdk/sin/` 暴露的 Python SDK（`sin.frames.send`、`sin.ui.create_window` 等）调用宿主能力。
- 构建系统为 CMake 3.21+，顶层 `CMakeLists.txt` 启用 AUTOMOC/UIC/RCC，子目录分别添加 `src/`、`drivers/`、`tests/`；第三方依赖集中于 `third_party/`（dbcppp、spdlog、concurrentqueue、nlohmann_json、pugixml、qcustomplot、vector_blf）。

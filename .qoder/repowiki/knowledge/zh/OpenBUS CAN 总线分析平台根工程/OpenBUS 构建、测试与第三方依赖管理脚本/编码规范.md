- 构建脚本统一通过 Environment 类集中发现 Qt/MinGW/CMake/Ninja 路径，并以 set_build_dir() 动态切换 BUILD_DIR/EXECUTABLE 支持多构建目录（build 与 build-dev）。
- 所有外部工具调用均经 run_cmd() 包装，统一打印彩色日志、捕获输出到 .tmp/logs/ 并按返回码退出，避免分散的 subprocess.run 调用。
- 每个子命令对应一个 cmd_xxx(env, args) 函数，并通过 argparse subparsers.set_defaults(func=...) 绑定，保持命令处理逻辑与参数解析解耦。
- Windows 窗口相关脚本采用 .bat + .ps1 双实现：.bat 用于快速启动/诊断，.ps1 用于带 QT_DEBUG_PLUGINS 详细日志的插件加载检查，形成可重复的故障定位流水线。
- 第三方库通过 third_party/Dependencies.cmake 以 add_library INTERFACE IMPORTED / add_subdirectory / 静态库 三种方式统一暴露给主工程，避免在主 CMakeLists 中散落 include_directories。
- 脚本中对 openbus.exe 启动前统一调用 taskkill /F /IM openbus.exe 清理旧进程，再触发构建或运行，避免文件锁定导致的编译失败。

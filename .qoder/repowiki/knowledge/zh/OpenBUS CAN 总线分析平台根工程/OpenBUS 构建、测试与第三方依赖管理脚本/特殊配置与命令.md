构建前需确保环境变量 SIN_QT_DIR / SIN_MINGW_DIR / SIN_CMAKE_DIR 指向 Qt6 mingw_64、MinGW bin、CMake bin；默认硬编码路径 D:\Qt\6.8.3\mingw_64 与 C:\Qt\Tools\mingw1310_64。常用命令：python scripts/build.py configure --build-type Dev --build-dir build-dev && python scripts/build.py build -j8 && python scripts/build.py deploy && python scripts/build.py test。窗口问题快速诊断：scripts\quick_start.bat 或 scripts\test_openbus.ps1。

- 每个 UI 区域拆分为独立 partial 文件（menubar、center-area、left-dock、right-dock、bottom-dock、dialogs、overlays、scenario-bar），由 loader 统一按 id→url 映射表加载并注入对应占位容器。
- 交互逻辑集中在 `ui-prototype.js` 的全局函数中（如 `toggleMenu`、`switchPanel`、`switchCenterTab`、`setScenario`），partial 中的 HTML 通过 `onclick` 直接调用这些函数，保持结构与行为解耦。
- 标签页/面板切换统一采用「移除所有 active/collapsed/open/checked 类 → 为目标元素添加对应类」的模式，避免状态残留。
- 中央标签页与左侧 ActivityBar/SideBar 通过 `tabPanelMap` 进行名称到面板名的映射，实现点击标签页自动联动侧栏、点击侧栏条目自动切换到对应标签页的双向同步。
- 主题系统通过 CSS 变量定义颜色，新增主题只需替换变量值，禁止在组件内硬编码具体色值以保证色彩一致性。

模块采用「单入口 HTML + 动态 partials」的轻量前端架构：`ui-prototype.html` 仅声明占位容器（如 `partial-menubar`、`partial-center-area` 等），由 `js/ui-loader.js` 在页面加载时并行 `fetch` 所有 `partials/*.html` 片段并注入对应 DOM；全部 partial 加载完成后调用全局 `initPage()` 绑定交互事件。`js/ui-prototype.js` 集中实现菜单下拉、ActivityBar/SideBar 切换、中央标签页与右侧/底部 Dock 的 tab 切换、右键菜单、拆分视图以及场景切换器 `setScenario`，并通过 `switchCenterTab` 与左侧栏面板建立双向联动。样式集中在 `css/ui-prototype.css`，主题系统通过 CSS 变量驱动 Light/Dark/VS Code/Monokai/Solarized 等 7 套配色。`ui-layout.md` 作为唯一权威布局描述，规定窗口结构、各 Dock 尺寸、颜色与字体规范，是 Qt 实现的输入契约。依赖方向单向：HTML → loader → partials → prototype.js → css，无框架或构建产物。

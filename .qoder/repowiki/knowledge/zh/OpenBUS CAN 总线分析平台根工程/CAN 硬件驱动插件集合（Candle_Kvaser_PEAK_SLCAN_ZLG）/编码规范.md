- 每个驱动子目录遵循统一结构：CMakeLists.txt + driver.json + <vendor>_driver_plugin.{h,cpp}，并通过 qt_add_plugin 生成 driver_<vendor>.dll 输出到 bin/drivers/<vendor>/。
- 插件类同时继承 QObject 与 CanDriverPlugin，使用 Q_PLUGIN_METADATA 指定固定 IID 和同目录 driver.json 文件，并实现 driverId/displayName/version/deviceTypes/enumerateDevices/createDevice。
- 设备能力与厂商 SDK 依赖通过 driver.json 声明（devices 数组含 type/name/channels/canFd/hasHwTimestamp/vid/pid，vendorSdk 含 dll/bundled/license），而非硬编码在 C++ 中。
- 具体设备通信逻辑与插件分离：插件只负责注册与 ICanDevice 创建，真实实现放在 src/core/candevice_<vendor>.cpp/h，插件 CMakeLists 通过绝对路径引用这些源文件。
- 各驱动 CMakeLists 顶部以注释说明目标、版本、ABI 约定及 .odp 打包产物位置，保持构建脚本风格一致。

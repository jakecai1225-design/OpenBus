模块按厂商划分为 candle、kvaser、peak、slcan、zlg 五个子目录，每个子目录是一个独立的 Qt 插件目标（qt_add_plugin），由顶层 drivers/CMakeLists.txt 通过 add_subdirectory 统一注册，并使用 deploy_driver_manifest 在构建后复制 driver.json 到输出目录。

- 插件契约：每个驱动实现一个继承 QObject + CanDriverPlugin（来自 src/core/driver/candriverplugin.h）的类，并通过 Q_PLUGIN_METADATA(IID "com.sin.openbus.CanDriverPlugin/1.0" FILE "driver.json") 声明元数据；driver.json 描述 id、设备类型、vid/pid、vendor SDK 依赖等，供运行时 DriverRegistry 加载。
- 核心逻辑解耦：每个插件仅包含 driver_plugin.{h,cpp}，实际设备枚举与通信逻辑位于 src/core 下的 candevice_<vendor>.cpp/h（如 CanDeviceCandle、CanDeviceKvaser 等），插件层只做 ID 注册与 ICanDevice::createDevice 分发。
- 厂商 SDK 集成方式不同：candle/kvaser/peak/slcan 通过 vendor 目录中的第三方 DLL（libusb-1.0.dll、canlib32.dll 等）动态加载；zlg 直接静态链接 driver/zlgcan.h/.dll/.lib 及 ZPS 内核库（ZPSCANFD.dll、CANDevCore.dll 等），并在 driver/zlgcan.h 中定义大量设备常量（ZCAN_USBCAN*、ZCAN_CANFDNET_* 等）。
- 资源：drivers/market/assets 存放各驱动图标 SVG，供市场/注册表展示使用。

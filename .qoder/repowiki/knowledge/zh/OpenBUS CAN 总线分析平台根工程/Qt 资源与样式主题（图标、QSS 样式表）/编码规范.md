- 样式通过 QSS 文件集中管理，并按功能区域（菜单栏、工具栏、标签页、表格、滚动条、状态栏等）以注释区块分隔组织。
- 针对应用自定义容器使用 ID 选择器（如 #ActivityBar、#SidePanelTitle、#BottomPanel、#RightPanel、#WindowButtons、#TerminalOutput），而非全局类型选择器，避免污染标准控件外观。
- 交互态通过伪类统一表达：:hover 高亮背景、:pressed 加深颜色、:checked 使用 #0066b8 蓝色强调色、:!checked 使用半透明灰色。
- 颜色体系围绕 #0066b8（主蓝）、#3b3b3b（正文）、#6c6c6c（次要文字）、#e4e4e4（边框）、#dcdcdc（悬停背景）等固定色值构建，保持 VS Code 风格一致性。
- SVG 图标文件名采用小写 kebab-case 命名（如 chevron-left.svg、zoom-in.svg），并在 resources.qrc 中按逻辑分组列出。

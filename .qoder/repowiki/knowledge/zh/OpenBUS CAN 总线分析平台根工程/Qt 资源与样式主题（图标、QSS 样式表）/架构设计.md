模块以 Qt Resource System（resources.qrc）为入口，将 resources/icons/*.svg 与 resources/styles/*.qss 打包进可执行文件，供 Qt 通过 :/ 前缀路径加载；styles/theme.qss 同时存在于 resources/styles 和顶层 styles 目录，作为可被外部覆盖的主题变体。resources.qrc 中所有资源统一挂载到 / 前缀下，按 icons/ 与 styles/ 子目录组织。panel-toggles.qss 独立于主样式，专门定义 QWidget#PanelTogglePanel 及其内部 QToolButton 的选中/悬停态，由业务代码按需加载。default.qss 是完整的 VS Code 风格浅色主题，覆盖 QMainWindow、QMenuBar、QDockWidget、QTabBar、QToolBar、QLineEdit、QPushButton、QTableView、QScrollBar、QStatusBar 等全部常用控件，并通过 #ActivityBar、#SidePanelTitle、#BottomPanel、#RightPanel、#WindowButtons 等 ID 选择器对应用自定义组件进行精细定制。

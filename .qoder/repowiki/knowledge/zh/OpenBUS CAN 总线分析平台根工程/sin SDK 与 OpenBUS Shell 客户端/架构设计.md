模块由两个独立子包组成：
- `sin/`：插件 SDK，以单例对象形式暴露 `output`、`frames`、`commands`、`workspace`、`signals`、`files`、`dbc`、`ui`（可选 PyQt6）等能力；所有 API 均通过 `_transport.py` 中的 `send_notification` / `send_request` 以 JSON-RPC 2.0 消息经 `sys.stdout` 发送给宿主进程，请求侧使用线程安全的 `_pending_requests` 字典 + `queue.Queue` 实现异步响应分发。
- `openbus_shell/client.py`：独立的 `OpenBusClient`，通过 TCP socket 向端口 5555 发送 JSON-RPC 2.0 文本流，封装 trace、dbc、file、system、ui 等 RPC 方法，供外部脚本或 AI Agent 直接调用。
依赖方向单向：各功能模块 → `_transport`，`__init__.py` 仅做聚合导出，不引入额外耦合。

- 每个功能域（frames、workspace、signals 等）定义一个下划线前缀的内部类（如 `_Frames`、`_Workspace`），并在模块末尾以同名小写实例暴露为全局单例。
- 对外 API 统一通过 `_transport.send_request` / `send_notification` 发起 JSON-RPC 调用，返回值按 `resp.get("result", {})` 模式解析，缺失时返回空列表或默认值。
- 可选依赖（如 PyQt6 的 `ui`）采用 try/except ImportError 包裹导入并设置 `_has_ui` 标记，避免缺少 UI 环境时报错。
- JSON-RPC 方法名采用 `模块.动词` 风格（如 `frames.getSelected`、`workspace.getProjectDir`、`trace.list`），客户端方法名与之形成一一对应。

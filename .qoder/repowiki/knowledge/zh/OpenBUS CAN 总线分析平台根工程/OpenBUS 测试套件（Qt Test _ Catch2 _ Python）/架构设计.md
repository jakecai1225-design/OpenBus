测试按被测模块划分为多个独立可执行目标：B1-B7 数据层测试（canfileio、filterengine、tracecore、dbc、sim_rec_play、market_driver、project、protocol）通过 `openbus_add_test` CMake 函数统一注册，每个文件定义一个继承自 QObject 的测试类并使用 QTEST_GUILESS_MAIN；UI 相关测试 `test_ui_offscreen.cpp` 单独使用 `qt_add_executable` 链接 openbus_ui/openbus_market/openbus_transceive/openbus_dbc/openbus_flow/openbus_trace/openbus_graphic，并设置 `QT_QPA_PLATFORM=offscreen` 在无头模式下运行。`test_runner.cpp` 通过 include 所有单测源文件并在 `main()` 中调用 `QTest::qExec` 依次执行 B1-C 阶段，作为全量入口。此外，`test_shell.cpp` 使用 Catch2 框架对 shell 协议进行纯 C++ 单元测试，`test_perf_shell.py` 是独立的 Python 性能基准脚本，通过 TCP 套接字向运行中的 Shell Server 发送 OAI-02 二进制帧以测量吞吐与时延。CMakeLists.txt 还定义了顶层 `tests` 自定义目标聚合全部测试可执行文件。

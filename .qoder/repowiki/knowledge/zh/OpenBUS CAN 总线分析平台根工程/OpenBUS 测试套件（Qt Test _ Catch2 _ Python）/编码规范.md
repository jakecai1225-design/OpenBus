- 每个被测模块对应一个 `test_*.cpp` 文件，内部定义继承 QObject 的测试类并以 `private slots:` 声明测试方法，遵循 QTest 命名约定。
- 测试数据路径统一通过 `SIN_SOURCE_DIR` 宏拼接至 `${SIN_SOURCE_DIR}/test/resources/`，由 CMake 在编译时注入。
- 可选的外部资源用例使用 `if (!QFile::exists(path)) QSKIP("...")` 跳过，保证缺少第三方样本时测试不失败。
- 断言统一使用 QTest 宏（`QVERIFY`/`QCOMPARE`/`QVERIFY2`/`QSKIP`），错误信息通过 `qPrintable` 格式化输出。
- CMake 中以注释标注所覆盖的需求编号（如 TC-01、ST-01、TF-xx、PRJ-xx、MKT-xx），将测试与需求追踪关联。
- Shell 协议测试使用 Catch2 的 `TEST_CASE` + `[tag]` 标签组织，按 protocol/registry/executor/integration 等维度分组。

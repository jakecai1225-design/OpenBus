- 每个插件目录自包含 main.py、plugin.json、icon.svg，并通过 plugin.json 的 activationEvents 和 contributes.commands 向宿主暴露命令入口。
- 需要 DBC 能力的插件在自身目录下复制一份 dbcparse.py，而非从 _shared 导入，以保持插件间 DBC 解析实现的隔离。
- 主循环通过 import sin 获取宿主帧回调（如 on_frame），并以模块级全局变量维护插件状态（如 _widgets、_values、_paused）。
- DBC 解析统一使用 Signal.raw_to_phys / phys_to_raw 配合 extract_intel/extract_motorola 处理 Intel 与 Motorola 字节序。
- ISO-TP 相关插件通过相对路径 from .isotp_client 或直接 import isotp_client 复用 _shared 中的 ISO-TP 客户端。
- OAI 工作流采用 TypedDict 定义 AgentState，将 LangGraph 节点函数按 collect_context → classify_intent → execute_query/action → format_response 的顺序编排。

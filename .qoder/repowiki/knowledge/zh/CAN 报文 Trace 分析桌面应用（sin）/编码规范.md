- 核心单例类（AppConfig、SessionManager、ThemeManager、DbcManager、ProjectManager 等）统一通过静态 `instance()` 获取全局实例。
- CAN 设备抽象遵循 `ICanDevice` 接口，各厂商实现（ZLG、PEAK、Kvaser）位于 `core/candevice_*.h/.cpp`，由 `CanDeviceManager` 按 `DeviceKind` 枚举选择具体后端。
- 高吞吐场景下帧数据通过 `RingBuffer` + `pendingFrames` 批处理提交，使用 `QTimer` 控制刷新率（High/Medium/Low/Paused），避免 UI 阻塞。
- UI 组件通过 `Q_PROPERTY` 暴露状态并在构造函数中连接信号槽，复杂视图（如 TraceView）重写 `setModel` 自动注入列头菜单与筛选逻辑。
- 过滤与着色规则统一通过 `FilterEngine` 表达式求值，颜色规则以 `ColorRule { expr, background, foreground }` 结构保存并可独立开关。
- 行级标记/着色/标签使用 `seqCounter`（永不回退的帧序列号）作为 key 存储在 `QSet/QHash` 中，确保环形缓冲区覆盖后仍保持语义一致性。

- 每个业务 DLL 仅暴露一个 C 风格工厂函数（openbus_createXxxModule），由主程序通过 ModuleRegistry 统一发现与创建
- 跨 DLL 共享的单例（AppConfig、DbcManager、PluginManager、ThemeManager、ModuleRegistry 等）集中在 openbus_data 中保持进程唯一
- UI 组件按功能拆分为 tab/page 类并通过 Module 适配器接入侧栏，不直接耦合主窗口
- CMake 使用 target_precompile_headers 为每个目标维护精简的 Qt 头清单以加速编译
- 测试按业务域拆分独立可执行（test_canfileio、test_dbc、test_protocol 等），对应 src/core 子目录

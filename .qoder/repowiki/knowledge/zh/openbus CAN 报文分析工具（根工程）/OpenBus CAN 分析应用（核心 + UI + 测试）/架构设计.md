源码按四层组织：core/ 提供 CAN 设备抽象、DBC/协议解析、文件 I/O、录制回放、过滤引擎、项目与会话管理等纯业务逻辑；models/ 暴露基于 QAbstractTableModel 的 Trace 数据模型；utils/ 提供环形缓冲、消息队列等通用原语；ui/ 承载主窗口与各业务页面。CMakeLists.txt 将所有层编译进共享库 openbus_data（含 thememanager 单例），再派生出 openbus_market / transceive / dbc / flow / trace / graphic 六个业务 DLL，每个 DLL 仅导出一个 C 工厂函数（如 openbus_createTraceModule），由 main.cpp 通过 ModuleRegistry 动态注册并统一调度。core/plugin 与 core/module 构成插件/模块双机制，使 UI 壳与业务实现解耦。tests/ 使用 Qt Test 对 core 各子系统及 offscreen UI 进行 L1/L2 分层验证，与 src/ 一一对应。

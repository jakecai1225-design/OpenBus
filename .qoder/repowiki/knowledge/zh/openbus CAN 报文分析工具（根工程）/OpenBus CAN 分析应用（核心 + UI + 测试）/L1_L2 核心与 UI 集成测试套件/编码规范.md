- 每个测试文件对应一个业务子域（B1~B8），文件名与 CMake 中注册的套件名一一对应，便于按模块独立构建与运行。
- 测试类继承 QObject 并使用 `Q_OBJECT` 宏，测试方法声明在 `private slots:` 下，遵循 Qt Test 标准组织方式。
- 通过 `SIN_SOURCE_DIR` 宏拼接 `/test/resources/` 路径加载样本数据，并以 `QFile::exists` + `QSKIP` 处理可选大样本缺失的情况。
- 断言策略区分两类：对真实样本仅校验结构自洽不变量（如 DLC 范围、ID 位宽、时间戳单调），对语义正确性使用 `writeSyntheticDbc`/`makeFrame` 等自构造数据进行精确值断言。
- 资源清理统一使用 RAII 容器（QTemporaryDir/QTemporaryFile），测试结束后自动删除临时文件。
- 性能回归通过 `QElapsedTimer` 记录耗时并设置宽松上限（如大 BLF 加载 <120s），输出基线日志而非严格阈值。

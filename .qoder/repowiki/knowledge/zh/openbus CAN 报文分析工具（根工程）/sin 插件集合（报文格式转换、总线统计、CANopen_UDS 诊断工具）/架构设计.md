每个子目录是一个独立插件，遵循统一的 sin 插件契约：plugin.json 声明 name/version/description/main/icon/activationEvents/contributes.commands；main.py 暴露 activate(context) 与 deactivate() 生命周期函数，由宿主在 onCommand 事件时加载。UI 通过 sin.ui.create_window 创建窗口，使用 PyQt6 构建界面；底层能力通过 sin.* 宿主 API 访问（如 sin.files.convert、sin.frames.send、sin.output.append）。依赖方向单向：插件 → sin 宿主 → C++ 引擎（blf-converter、dbc-tool 等标注“宿主 C++ 解析引擎”），插件自身不实现核心协议栈。uds-diagnostic 是内部结构最复杂的插件，将 ISO-TP 传输层（uds_isotp.py）、UDS 客户端与服务编解码（uds_client.py）、DID 字典（dids.json）与主 UI（main.py）分层组织，并附带 tests/test_proto.py、tests/test_e2e.py 单元测试。

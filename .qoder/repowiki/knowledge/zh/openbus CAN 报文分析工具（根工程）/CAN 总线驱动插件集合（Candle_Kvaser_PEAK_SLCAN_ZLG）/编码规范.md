- 每个 vendor 子目录自成独立 CMake target，使用 `qt_add_plugin(driver_<id>)` 并通过 `set_target_properties` 将输出定向到 `${CMAKE_BINARY_DIR}/bin/drivers/<id>/`。
- 插件源文件统一命名为 `<vendor>_driver_plugin.{h,cpp}`，类名形如 `<Vendor>DriverPlugin` 并继承 `QObject` 与 `CanDriverPlugin` 接口。
- 通过 `Q_PLUGIN_METADATA(IID "com.sin.openbus.CanDriverPlugin/1.0" FILE "driver.json")` 声明插件元数据，且 `driver.json` 中的 `id` 必须与插件目录名一致。
- 后端实现通过 `target_sources` 直接引用 `src/core/candevice_<vendor>.h/.cpp`，而非链接为独立库，保证插件与主程序 ABI 一致。
- `driver.json` 中以数组形式枚举所有支持的设备类型，并为每种设备标注 `type`、`name`、`channels`、`canFd`、`hasHwTimestamp` 及 `vid/pid`。
- 对需要第三方 DLL 的 vendor（如 candle 的 libusb），在 `driver.json` 的 `vendorSdk.dll` 列表中声明并在 `bundled` 字段注明是否随包分发。

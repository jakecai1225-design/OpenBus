- 所有脚本以 `#!/usr/bin/env python3` 开头并通过 `argparse` 定义子命令，错误时打印彩色 `[INFO]/[ OK ]/[WARN]/[FAIL]` 标记并返回非零退出码。
- 外部工具路径统一通过环境变量 `SIN_*_DIR` 覆盖默认值，再以 `os.environ['PATH'] = ... + os.pathsep + PATH` 前置 MinGW/CMake/Qt bin，避免 cc1plus 找不到 DLL 静默崩溃。
- 打包器（driver_tool.py、plugin_tool.py）对 zip 包内条目做路径穿越防护（拒绝 `/` 开头与 `..`），并以单行 JSON 结果（`_emit(ok, **kwargs)`）作为 CLI 协议供 C++ QProcess 解析。
- 构建产物采用白名单拷贝策略：`package.py` 中 `BIN_FILES`/`BIN_DIRS`/`PYQT6_MODULES`/`SYSTEM_DLLS` 显式声明允许项，未命中即跳过或报错，确保分发物最小化且可审计。
- Windows 管道编码统一通过 `sys.stdout.reconfigure(encoding='utf-8')` 强制 UTF-8，避免 GBK 管道导致主程序 JSON 解析失败。
- 增量构建前先调用 `kill_running_executable()` 使用 `taskkill /F /IM openbus.exe` 释放文件锁，再尝试独占打开目标文件确认进程已退出后才继续编译。

构建前需设置环境变量 `SIN_QT_DIR` / `SIN_MINGW_DIR` / `SIN_CMAKE_DIR`（或默认路径 `C:/Qt/...`、`C:/tools/cmake-3.30.3-windows-x86_64`）；完整打包：`python scripts/package.py --version X.Y.Z -j8`；构建 Dev 档：`python scripts/build.py configure --build-type Dev --build-dir build-dev && python scripts/build.py build --build-dir build-dev -j8`；生成本地市场：`python scripts/make_market.py`；下载 libusb：`python scripts/download_libusb.py`。

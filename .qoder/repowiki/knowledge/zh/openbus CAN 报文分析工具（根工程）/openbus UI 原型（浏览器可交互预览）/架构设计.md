采用「骨架页面 + 动态 partials」的分层结构：`ui-prototype.html` 仅定义占位容器（如 `partial-menubar`、`partial-center-area` 等），由 `js/ui-loader.js` 在启动时并行 `fetch` 所有 `partials/*.html` 并注入对应 DOM；全部 partial 加载完成后回调全局 `initPage()` 完成右键菜单等初始化。

- 样式集中在 `css/ui-prototype.css`，使用 CSS 类名驱动状态切换（`.active`、`.open`、`.checked` 等），无框架依赖。
- 交互逻辑集中在 `js/ui-prototype.js`，以全局函数形式暴露场景切换入口 `setScenario(name)`，内部再调用 `switchPanel` / `switchCenterTab` / `switchRightTab` / `switchBottomTab` 等专用切换器，并通过 `tabPanelMap` 实现中央标签页与左侧 ActivityBar/SideBar 的双向联动。
- 视图内容按区域拆分为 8 个 partial 文件（menubar、left-dock、center-area、right-dock、bottom-dock、scenario-bar、dialogs、overlays），每个 partial 只负责自身区域的 HTML 片段。
- `ui-layout.md` 是唯一的权威布局规范文档，描述窗口结构、各 Dock 行为、色彩/字体主题及变更记录，作为 Qt 实现的输入依据。
- 依赖方向单向：HTML → loader → partials → prototype.js → CSS，不存在反向引用。

- 每个 UI 区域以独立 partial 文件组织（位于 `partials/`），并在主页面中以 `<div id="partial-*">` 占位，由 `ui-loader.js` 统一映射并注入。
- 面板/标签页的状态切换统一通过添加移除 `.active` 类来实现显示/隐藏，而非操作 `display` 属性。
- 菜单下拉通过 `.menu-item.open` 控制可见性，点击外部区域调用 `closeMenus()` 统一收起，避免多个菜单同时展开。
- 场景切换集中由 `setScenario(name, btn)` 一个入口分发，内部组合调用 `switchPanel` / `switchCenterTab` / `switchRightTab` / `switchBottomTab` 等专用切换器，保持多区域状态一致。
- 中央标签页与左侧 ActivityBar/SideBar 通过 `tabPanelMap` 名称映射实现双向联动，新增标签页只需在映射表中登记即可自动同步侧栏。
- CSS 类名遵循 BEM 风格前缀约定（如 `.menubar .menu-item .menu-dropdown`、`.center-tabs .ctab`、`.dock-pane`），同一区域样式集中书写并按功能区块分段注释。

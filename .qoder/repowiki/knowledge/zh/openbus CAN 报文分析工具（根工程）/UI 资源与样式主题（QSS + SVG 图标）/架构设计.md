本模块由三类静态资源组成：
- `resources/resources.qrc`：Qt 资源清单，将 `styles/` 下的 QSS 文件与 `icons/` 下的全部 SVG 图标注册到 `:/` 前缀下，供 C++ 端以 `:icons/xxx.svg`、`:/styles/...` 路径引用。
- `resources/styles/default.qss`：硬编码颜色的默认浅色主题（VS Code 风格），直接作为 QSS 被应用加载。
- `resources/styles/theme.qss` 与 `styles/theme.qss`：两套主题模板，使用 `@varName` 占位符（如 `@windowBg`、`@accent`、`@border`、`@spinUp`、`@treeChevronRight` 等），由运行时的 ThemeManager 读取后做字符串替换再注入到 QApplication；该设计使换肤无需重新编译。
- `resources/icons/`：扁平化 SVG 图标库，按语义命名（如 `chevron-*`、`win-*`、`trace.svg`、`project.svg` 等），被 QSS 通过 `url(:icons/...)` 引用，勾选框、树分支箭头、窗口控制按钮等均依赖这些图标。
依赖方向单向：C++ 界面层 → Qt 资源系统 → 本模块的 QSS/SVG，模块内部无代码逻辑。

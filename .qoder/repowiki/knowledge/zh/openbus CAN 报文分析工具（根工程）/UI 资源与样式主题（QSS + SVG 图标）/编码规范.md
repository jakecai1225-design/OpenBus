- 主题模板统一使用 `@变量名`（如 `@windowBg`、`@accent`、`@border`、`@spinUp`）代替硬编码颜色或图片路径，由 ThemeManager 运行时替换。
- QSS 按功能区域分节注释组织（菜单栏、DockWidget、工具栏、标签页、输入框、表格、滚动条、状态栏、窗口控制按钮等），便于定位与维护。
- 控件样式通过类选择器（`QToolBar QToolButton`）和 ID 选择器（`#ActivityBar`、`#BottomPanel`、`#WindowButtons`）组合覆盖，ID 用于特定面板级定制。
- SVG 图标一律通过 Qt 资源路径 `url(:icons/文件名.svg)` 引用，而非相对路径，确保跨平台一致。
- 深色主题相关规则对 `#TerminalOutput`、`#TerminalPrompt` 等终端面板单独设置背景/前景色，使其与通用浅色内容区区分开。

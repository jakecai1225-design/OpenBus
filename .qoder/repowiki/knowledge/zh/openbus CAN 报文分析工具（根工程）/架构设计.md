根目录通过 `CMakeLists.txt` 作为单一入口，依次 `add_subdirectory(src)`、`drivers`、`tests`，将核心应用、厂商驱动插件与 Qt Test 集成测试纳入同一构建树；`src/` 下的 core_application 通过 C 工厂 + ModuleRegistry 在运行时动态加载 drivers/*.odp 与 plugins/*.opk，形成“主进程 + 可插拔驱动/插件”的装配模型。Python 侧由 sdk 提供 JSON-RPC over stdin/stdout 宿主通信层，被 plugins 子模块调用并与主程序交互；ui_prototype 与 resources_and_styles 为 Qt UI 实现前的布局与主题验证资产；build_scripts 集中封装 CMake/Qt 构建、Release 打包、驱动与插件市场生成等全链路命令，使各子模块共享同一套构建与发布流程。

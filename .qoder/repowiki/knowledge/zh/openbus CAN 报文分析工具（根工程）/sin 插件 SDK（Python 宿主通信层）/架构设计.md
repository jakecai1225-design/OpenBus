模块采用「薄 API + 共享传输层」的分层设计：`_transport.py` 是唯一的底层通道，基于 `json.dumps` + `sys.stdout` 实现 JSON-RPC 2.0 通知/请求-响应，并通过 `queue.Queue` + `threading.Lock` 维护 pending 请求表，由宿主通过 `deliver_response` 投递响应；其余各子模块（`commands.py`、`frames.py`、`signals.py`、`workspace.py`、`files.py`、`dbc.py`、`output.py`、`ui.py`）各自定义一个 `_Xxx` 类并导出单例实例（如 `frames = _Frames()`），统一通过调用 `_transport.send_notification` / `send_request` 与主程序交互。`__init__.py` 作为插件入口，聚合所有子模块并在 PyQt6 缺失时优雅降级不暴露 `ui`。依赖方向严格单向：业务 API → `_transport` → 标准 I/O，插件侧不直接读写 stdout。异步回调场景（`files.convert`）通过 `_callbacks` 字典按 `jobId` 注册 `on_progress`/`on_finished`，由宿主反向调用 `handle_notification` 分发。

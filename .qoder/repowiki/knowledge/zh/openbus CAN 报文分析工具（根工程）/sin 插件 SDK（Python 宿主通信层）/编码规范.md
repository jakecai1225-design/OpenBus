- 每个能力模块定义一个 `_Xxx` 类并以同名模块级单例实例导出（如 `frames = _Frames()`），插件通过 `sin.frames` 等方式访问。
- 对外方法统一通过 `_transport.send_notification`（单向通知）或 `send_request`（同步请求+超时）与主程序通信，不直接操作 I/O。
- 请求参数中的 bytes 数据在发送前统一转换为 hex 字符串（如 `bytes.fromhex`/`.hex()`），接收端再还原。
- 对宿主的返回值采用统一的 `{"result": ..., "error": ...}` 结构，API 层在 None/result 缺失时返回安全默认值（空列表、空 dict、None）。
- 需要跨线程回调的能力（如 files 转换）使用 `threading.Lock` 保护全局回调字典，并按 `jobId` 键管理生命周期。

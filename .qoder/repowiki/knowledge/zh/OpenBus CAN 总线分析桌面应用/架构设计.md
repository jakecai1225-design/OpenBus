项目采用 CMake + Qt6 构建，顶层 `CMakeLists.txt` 定义 `openbus` 工程并引入 `third_party/Dependencies.cmake`；`src/CMakeLists.txt` 将源码拆分为三个目标：`openbus_core`（静态库，含 core/models/utils，提供 CanFrame、设备抽象、DBC、文件 I/O、过滤引擎、插件宿主等核心逻辑）、`openbus_ui`（静态库，封装所有 Qt 界面组件）和最终可执行目标 `openbus`（仅包含 `main.cpp` 及资源）。入口 `src/main.cpp` 初始化日志、配置、会话、主题后创建 `MainWindow` 启动事件循环。UI 层通过 `ui/mainwindow` 组合 `activitybar`、`bottompanel`、`rightpanel`、`spliteditorarea` 等面板，各功能以 Tab/Dock 形式挂载（traceview、recordtab、playbacktab、signalsendtab、offlineanalysistab、dbcdetailtab、udsview、canopenview 等）。核心依赖方向严格单向：UI → models → core → utils/third_party；core 不反向依赖 UI。第三方库（spdlog、nlohmann_json、pugixml、qcustomplot、vector_blf、concurrentqueue）集中管理于 `third_party/`，并通过 `target_include_directories` 暴露给 `openbus_core`。Windows 下通过 `POST_BUILD` 命令将 `driver/` 目录下的 ZLG/PEAK/KVASER 等硬件 DLL 复制到 exe 同级目录，运行时由 `candevice_zlg/peak/kvaser` 动态加载。Python 插件位于 `plugins/`，每个插件含 `plugin.json` 与 `main.py`，由 `core/plugin/pluginmanager` 通过 `pluginhost` 加载；Python SDK 位于 `sdk/sin/`，提供 `__init__.py`、`commands.py`、`frames.py`、`signals.py`、`workspace.py`、`ui.py` 等模块供插件调用。`resources/` 通过 `resources.qrc` 打包 SVG 图标与 QSS 样式，`UI/` 为独立的 HTML/JS/CSS 原型页面，与 Qt 主程序解耦。

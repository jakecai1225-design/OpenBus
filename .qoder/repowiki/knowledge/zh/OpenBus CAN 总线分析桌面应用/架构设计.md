采用 CMake + Qt6 构建的三层架构：
- 核心静态库 `openbus_core`（src/core）：封装 CAN 设备抽象接口 `ICanDevice`（ZLG/PEAK/Kvaser/TongXing/S-LAN 多后端），通过 `CanDeviceManager` 统一调度；提供 DBC/ARXML 导入导出、BLF/ASC/CSV/PCAP/TRC 文件 I/O、过滤器引擎、录制/回放/模拟器、项目与会话管理、日志等。
- UI 静态库 `openbus_ui`（src/ui）：以 `MainWindow` 为根，组合 ActivityBar、BottomPanel、RightPanel、SplitEditorArea 等面板，实现 TraceView、GraphicView、SignalSendTab、RecordTab、PlaybackTab、OfflineAnalysisTab、UDS View、CAN Open View 等功能视图，依赖 qcustomplot 绘制波形。
- 可执行目标 `openbus`（src/main.cpp）：注册 `CanFrame` 元类型，初始化 AppConfig/SessionManager/ThemeManager 后启动 MainWindow。
- 插件系统：C++ 侧 `PluginManager` 扫描 `plugins/*/plugin.json`，通过 `sin_host.py` 启动独立 Python 宿主进程，使用 JSON-RPC 双向通信转发帧事件与命令；Python SDK (`sdk/sin`) 暴露 output/frames/commands/workspace/signals/ui 等 API 供插件调用。
- 资源与驱动：`resources/` 通过 `.qrc` 打包图标与样式；`driver/` 包含 ZLG/ZPSCANFD 等厂商 DLL，构建后自动拷贝至 exe 同级目录。
- 第三方依赖集中于 `third_party/`（spdlog、nlohmann_json、pugixml、vector_blf、qcustomplot、concurrentqueue 等），由 `Dependencies.cmake` 引入。

- CAN 设备后端通过继承 `ICanDevice` 抽象接口实现，品牌标识使用枚举 `Brand`，并通过静态工厂 `ICanDevice::create(brand, subType)` 创建实例，使主程序与具体硬件解耦。
- 模块按职责拆分为 core/models/ui/utils 四个子目录，并通过 CMake 分别编译为 `openbus_core` 和 `openbus_ui` 两个静态库，UI 变更不触发 core 重编译。
- 单例组件（AppConfig、SessionManager、PluginManager、ThemeManager 等）提供 `instance()` 静态方法集中访问，并在 main() 中按固定顺序初始化。
- 日志统一通过 `logging::init()/shutdown()` 与 `OPENBUS_LOG_*` 宏输出，异常在 main 中捕获并以 QMessageBox 提示后安全关闭日志。
- Python 插件遵循 `activate(context)/deactivate()` 生命周期约定，通过 `context.on_frame()` 注册回调、`context.register_command()` 注册命令，并使用 `sin.output/frames/commands/workspace/signals` SDK 与主程序交互。
- 预编译头（target_precompile_headers）按 core/UI 分层分别维护精简 Qt 头列表，core 层仅包含基础容器与 QMetaType，UI 层才引入 QWidget/QMainWindow 等重型头以缩短编译时间。

- 业务模块通过 `extern "C" IBusinessModule* openbus_createXxxModule()` 工厂函数导出，模块内部类不跨 DLL 边界暴露，仅 `imodule.h` 中的 `IBusinessModule` 与 `ShellContext` 作为契约。
- 驱动插件遵循 `drivers/<id>/` 单目录结构，包含 `CMakeLists.txt`、`driver.json` 清单、`<id>_driver_plugin.{cpp,h}`，由 `drivers/CMakeLists.txt` 统一 add_subdirectory 并 POST_BUILD 复制清单至输出目录。
- Python 插件统一以 `plugin.json` 描述元信息、`main.py` 实现 `activate(context)` / `deactivate()` 生命周期函数，并通过 `sin.*` SDK（`sdk/sin/`）访问宿主能力，PyQt6 UI 按需导入避免无 PyQt6 时崩溃。
- UI 组件按功能拆分到 `src/ui/` 下的独立 `.h/.cpp` 文件（如 `mainwindow`、`activitybar`、`traceview`、`graphicview`、各 Tab），通过 `SplitEditorArea` 与 Dock 机制组合，而非单体大窗口。
- 核心数据结构（如 `CanFrame`）通过 `qRegisterMetaType` 注册为 Qt 元类型，以便跨线程信号槽传递；日志统一通过 `logging.h` 的 `OPENBUS_LOG_*` 宏输出。
- 构建配置在顶层 `CMakeLists.txt` 中集中声明 C++17、AUTOMOC/UIC/RCC、Qt 组件查找与子目录组织，第三方依赖通过 `third_party/Dependencies.cmake` 引入，保持根级构建脚本简洁。

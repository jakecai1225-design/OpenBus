- 业务模块通过 `extern "C" IBusinessModule *openbus_createXxxModule()` 工厂函数导出，模块内部类不跨 DLL 边界暴露，仅依赖 `imodule.h` 中的前向声明与 Qt 基础类型。
- 新增模块能力通过在 `IBusinessModule` 中追加带默认实现的虚函数（如 `pages()`、`createPage(id, param, ctx)`、`query()`、`invoke(action, arg)`）实现向后兼容，禁止修改既有签名。
- 驱动插件以 `drivers/<vendor>/` 子目录组织，每个包含 `CMakeLists.txt`、`driver.json`、`*_driver_plugin.{h,cpp}`，并通过 `deploy_driver_manifest` 在 POST_BUILD 阶段复制清单到输出目录。
- Python 插件统一采用 `main.py` 暴露 `activate(context)` / `deactivate()` 生命周期函数，使用 `sin` SDK 提供的 `context.on_frame()` 订阅帧、`sin.ui.create_window()` 创建独立窗口，并通过 `plugin.json` 声明元信息。
- UI 与数据层解耦：UI 模块通过 `ShellContext` 获取 `Player`/`Recorder`/`DeviceManager`/`DbcManager` 等后端指针，自身不持有全局单例，避免循环依赖。
- 日志统一通过 `logging::init()/shutdown()` 与 `OPENBUS_LOG_*` 宏输出，异常捕获集中在 `main()` 的 try/catch 块并以 QMessageBox 提示后退出。

工程采用「壳 + 业务 DLL + 原生驱动插件 + Python 插件」的分层架构：
- 入口 `src/main.cpp` 初始化 QApplication、日志、配置与会话，通过 `ModuleRegistry` 注册 market/transceive/dbc/flow 四个业务模块工厂函数（`extern "C" openbus_createXxxModule`），每个模块以独立 DLL 暴露 `IBusinessModule` 接口（定义于 `src/core/module/imodule.h`），实现 UI 页面创建与 shell 回调双向通信。
- 核心逻辑集中在 `src/core/`（CAN 帧、设备管理、DBC、文件 I/O、过滤引擎、播放器/录制器、会话/项目等），UI 层在 `src/ui/`（MainWindow、ActivityBar、SplitEditorArea、各 Tab 面板），数据模型在 `src/models/`（CanTraceModel + CanTraceProxyModel + ViewportProxy）。
- 硬件驱动以原生 QPluginLoader 动态库形式位于 `drivers/<id>/`（zlg/peak/kvaser/slcan/candle），每个驱动含 `driver.json` 清单与 `*_driver_plugin.{cpp,h}`，由 `DriverRegistry` 热加载；厂商 SDK 二进制（ZLG/Kvaser/PEAK 等）放在 `driver/kerneldlls/`。
- Python 插件体系位于 `plugins/<name>/`，每个插件含 `plugin.json`、`main.py`（实现 `activate(context)` / `deactivate()`）和可选 PyQt6 UI；`src/core/plugin/pluginmanager.h` 通过 `PluginHost` 启动独立 Python 宿主进程（`scripts/sin_host.py`），经 JSON-RPC 风格消息分发 CAN 帧、命令与文件/DBC 操作，SDK 封装在 `sdk/sin/`。
- 构建系统由顶层 `CMakeLists.txt` 组织，启用 AUTOMOC/UIC/RCC，第三方依赖集中声明于 `third_party/Dependencies.cmake`，测试目标在 `tests/` 并通过 `enable_testing()` 集成到 ctest。
- 资源与样式通过 `resources/resources.qrc` 与 `resources/styles/*.qss` 统一注入，UI 原型在 `UI/`（HTML+JS 静态原型）。

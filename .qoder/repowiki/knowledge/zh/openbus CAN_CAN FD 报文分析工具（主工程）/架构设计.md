工程以 CMake 为构建入口（CMakeLists.txt），通过 `add_subdirectory(src)` 编译主程序，`drivers/` 下每个厂商目录生成独立的 `.odp` 驱动插件 DLL，`plugins/` 下每个子目录是一个独立 Python 插件包（含 `main.py` + `plugin.json`）。

- 进程内模块拆分：`src/main.cpp` 仅负责初始化 QApplication、日志、配置与会话，并通过 `extern "C" IBusinessModule *openbus_createXxxModule()` 工厂函数将 market/transceive/dbc/flow/trace/graphic 六个业务模块注册到 `ModuleRegistry`；各模块实现位于 `src/ui/*module.*`，通过 `src/core/module/imodule.h` 定义的 `IBusinessModule` 接口与壳通信，遵循“只增不改”的向后兼容原则。
- 数据层与 UI 分离：`src/core/` 提供设备管理（`candevicemanager`）、帧模型（`canframe/busmessage`）、播放器/录制器（`player/recorder`）、DBC 管理（`dbcmanager`）、协议解析（`protocol/`）、文件 I/O（`canfileio/`、`file_import/`）、过滤引擎（`filter_engine`）等纯后端；`src/ui/` 基于 Qt Widgets 实现 VS Code 风格的主窗口、标签页、侧边栏与面板；`src/models/` 提供 Trace 表格的 Model/ProxyModel。
- 驱动系统：`drivers/<vendor>/` 下的 C++ 插件实现 `DriverPlugin` 接口，由 `src/core/driver/driverregistry.cpp` 通过 QPluginLoader 热加载，支持禁用/卸载与 `.odp` 包安装；`driver/market/assets/` 提供图标资源。
- Python 插件系统：`src/core/plugin/pluginmanager.cpp` 启动独立的 Python 宿主进程（`scripts/sin_host.py`），通过 JSON-RPC 风格的请求/响应机制分发帧事件、命令与 DBC 会话；插件通过 `sin` SDK（`sdk/sin/`）暴露 `activate(context)` / `deactivate()`，使用 `context.on_frame()` 订阅帧、`sin.ui.create_window()` 创建独立 PyQt6 窗口。
- 第三方依赖集中管理于 `third_party/`（dbcppp、qcustomplot、spdlog、nlohmann_json、pugixml、vector_blf、concurrentqueue 等），由 `third_party/Dependencies.cmake` 统一引入。
- 构建产物输出到 `build/bin`，驱动插件输出到 `build/bin/drivers/<id>/`，Python 插件无需编译直接按目录发现。

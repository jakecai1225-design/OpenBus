- 业务功能按模块拆分到独立 DLL，每个模块导出唯一命名的 `openbus_createXxxModule()` C 工厂函数，并通过 `ModuleRegistry::registerModule(name, factory)` 在启动时注册。
- 厂商硬件驱动以 `drivers/<id>/` 子目录组织，包含 `CMakeLists.txt`、`driver.json` 清单与 `<id>_driver_plugin.cpp/.h`，由顶层 `drivers/CMakeLists.txt` 统一纳入构建。
- Python 插件遵循统一结构：`main.py` 实现插件逻辑、`plugin.json` 声明元信息、`icon.svg` 图标，可选 `__pycache__` 缓存目录，通过 `sdk/sin/` 的 commands/transport 与宿主通信。
- Qt 类采用头文件声明 + 多 cpp 拆分实现（如 `mainwindow.h` + `mainwindow_actions.cpp` / `mainwindow_pages.cpp` / `mainwindow_chrome.cpp`），按职责域划分源文件。
- 核心单例通过 `ClassName::instance()->method()` 访问（如 `AppConfig`、`SessionManager`、`ModuleRegistry`、`ThemeManager`、`DbcManager`）。
- 日志统一通过 `OPENBUS_LOG_*` 宏（logging.h）输出，区分模块标签与级别，异常路径在 main 中捕获并弹窗后关闭日志系统。

- 所有子工程通过顶层 `CMakeLists.txt` 统一 C++17 标准、Qt AUTOMOC/UIC/RCC 开关与输出目录，禁止在子目录重复定义全局编译选项。
- 第三方依赖一律放入 `third_party/` 并以头文件或子工程形式由 `third_party/Dependencies.cmake` 暴露，避免直接散落到源码树。
- Python 插件遵循统一的 sin 宿主 API 契约（清单、消息协议、Job 模型），不得直接耦合 C++ 内部类型。
- Qt 界面资源（QSS、SVG、图片）集中置于 `resources/` 并通过 `resources.qrc` 注册，运行时按主题动态加载。
- 新增功能需在 `documentation/` 中补充设计文档后再进入实现，确保需求、架构与代码同步演进。

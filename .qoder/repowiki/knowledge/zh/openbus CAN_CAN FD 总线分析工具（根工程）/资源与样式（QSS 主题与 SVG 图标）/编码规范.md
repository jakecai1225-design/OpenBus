- SVG 图标按语义命名（如 `chevron-left.svg`、`zoom-in.svg`），并通过 `resources.qrc` 统一注册到 `/icons/` 虚拟路径下供 QSS 与 C++ 代码引用。
- QSS 文件顶部用注释块标明主题用途与风格定位（如 VS Code 风格、扁平简洁），并按全局、菜单栏、DockWidget、面板标题、列表、工具栏、标签页、输入框、按钮、表格等区块分段组织。
- 主题模板 `theme.qss` 仅使用 `@变量` 占位符表达颜色与尺寸，不出现具体十六进制色值，确保换肤时只需替换变量映射而不改动样式结构。
- 对特定业务组件通过固定 objectName（如 `#ProjectList`、`#ActivityBar`、`#CollapsibleTitle`、`#SidePanelTitle`、`#BottomPanel`、`#ContentTree`）编写 ID 选择器，保证样式与 UI 结构解耦。

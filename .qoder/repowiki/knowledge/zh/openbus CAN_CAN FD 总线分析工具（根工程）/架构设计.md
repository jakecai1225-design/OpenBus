根目录通过 `CMakeLists.txt` 作为唯一入口：声明 Qt6 组件、启用 AUTOMOC/UIC/RCC、引入 `third_party/Dependencies.cmake` 聚合所有第三方库，并依次 `add_subdirectory(src)`（核心引擎 + UI）、`drivers`（原生 .odp 驱动插件）。Python 侧的 `plugins/`（BLF 转换、UDS、CANopen、DBC、统计）与 `scripts_and_build/`（构建、打包、本地市场生成、宿主进程）通过宿主 sin API 与 C++ 引擎解耦；`resources_and_styles/` 经 `resources.qrc` 被 Qt 资源系统统一注入；`documentation/` 提供 Trace/Graphic/插件/驱动方案的设计依据，反向约束各子模块演进。整体形成「C++ 主进程 + Python 插件进程 + Qt 资源/样式」的分层架构，由顶层 CMake 与脚本集完成装配与分发。

- 每个可独立展示的面板以 `partials/<name>.html` 形式拆分，并在主 HTML 中以 `id="partial-<name>"` 的占位 div 预留挂载点。
- 面板内标签页/子区域统一通过添加或移除 `.active` class 来切换显示，JS 中先遍历清除再对目标元素追加该类。
- 菜单/下拉项使用 `.open` / `.checked` / `.unchecked` 等语义化 class 表示展开与选中状态，并通过 `closest()` 判断点击范围。
- 场景切换由单一 `setScenario(name, btn)` 函数分发，内部组合调用 `switchPanel`、`switchCenterTab`、`switchRightTab`、`switchBottomTab` 等专用切换函数，保持多面板联动一致。
- 右侧栏、底部栏、中央区的标签切换采用相同模式：`querySelectorAll('.dtab')` 清除 active，再用 `data-tab` 属性定位目标标签。
- 所有交互逻辑集中在 `ui-prototype.js` 的全局函数中，并由 `ui-loader.js` 在所有 partial 加载完毕后统一调用 `initPage()` 完成事件绑定，避免 partial 未就绪导致的空引用。

模块以单页 HTML `ui-prototype.html` 为入口，使用占位 `<div id="partial-*">` 作为插槽；`js/ui-loader.js` 在页面启动时并行 `fetch` 8 个 `partials/*.html` 片段并注入对应容器，全部加载完成后调用全局 `initPage()` 绑定事件。`js/ui-prototype.js` 集中实现所有交互逻辑（菜单下拉、ActivityBar/SideBar/CenterArea/RightDock/BottomDock 的标签切换、右键上下文菜单、拆分视图、场景切换器），通过操作 DOM class（如 `.active`、`.open`）驱动视图状态。样式集中在 `css/ui-prototype.css`。`ui-layout.md` 是权威布局描述文档，规定 Qt 实现需严格遵循的窗口结构、尺寸、主题与交互约定，形成「文档 → 浏览器原型确认 → Qt 实现」的工作流。依赖方向单向：HTML 骨架 → loader 注入 partials → prototype 脚本绑定行为，无跨文件 JS 模块依赖。

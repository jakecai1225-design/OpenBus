本模块为纯文档目录，包含五份 Markdown 文档与两张 drawio/drawio.svg 架构图，覆盖三个核心主题：
- `需求文档.md`：以 v2.0 版本梳理 Trace 页面已实现 48 项功能、12 项下一步实施需求（S01–S12）与 15 项备选需求（B01–B15），按难度/工时排序并标注涉及源文件。
- `插件系统方案.md`：定义 VS Code 风格的 Python 插件体系——每插件独立进程、Named Pipe 双通道（JSON-RPC 控制 + 自定义二进制数据协议）、声明式 `plugin.json` 贡献点、订阅制数据推送、协议版本协商与 ABI 契约冻结。
- `驱动系统方案.md`：将采集硬件驱动从静态编译迁移为可热加载的 Qt 原生插件（`.odp` 包，通过 `QPluginLoader` 在主进程内加载），由 `DriverRegistry` 统一扫描注册，并通过统一市场标签页（MarketTab）与 Python 插件市场合并；v2 阶段已将 ZLG/PEAK/Kvaser 三家内置收敛为仅 openbus 官方模拟器，其余厂商一律通过市场安装。
- `Graphic模块设计文档.md`、`Trace模块设计文档.md`：分别描述图形视图与 Trace 模块的内部设计要点。
- `architecture.drawio` / `drawio.svg`：提供可视化架构图供查阅。

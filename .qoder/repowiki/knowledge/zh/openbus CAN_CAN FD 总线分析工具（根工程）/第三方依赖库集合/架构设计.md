该目录为纯第三方依赖聚合层，不包含业务代码，仅通过 `Dependencies.cmake` 将各子库以 CMake target 形式暴露给上层构建：
- 头文件-only 库：`spdlog`（INTERFACE IMPORTED，仅设置 include 路径）、`nlohmann_json`（单头文件 json.hpp）、`concurrentqueue`（`blockingconcurrentqueue.h`/`concurrentqueue.h` 两个头）。
- 源码静态库：`qcustomplot` 在存在 `.h/.cpp` 时编译为 STATIC 库并链接 Qt6::Widgets、Qt6::PrintSupport。
- 可嵌入子工程：`vector_blf`、`dbcppp`（含完整 CMakeLists.txt 与 src/include）、`dbcppp_src`（可能为打包源），通过 `add_subdirectory` 或 include 路径引入。
依赖方向单向：上层项目通过 `CMAKE_SOURCE_DIR/third_party/*` 路径引用这些库，本目录不反向依赖项目代码；`dbcppp.zip` 为 dbcppp 的归档备份。

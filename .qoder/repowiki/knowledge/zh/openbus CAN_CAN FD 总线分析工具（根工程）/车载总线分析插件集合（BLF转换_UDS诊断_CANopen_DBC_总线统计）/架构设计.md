每个子目录是一个自包含的插件包，遵循统一约定：plugin.json 声明 name/version/author/description/main/icon/activationEvents/contributes.commands；main.py 暴露 activate(context) / deactivate() 两个入口，由宿主在命令触发时加载。插件通过 `import sin` 访问宿主能力：sin.ui.create_window 创建 Qt 窗口，sin.frames.send/on_frame 收发 CAN 帧，sin.files.convert/cancel 调用 C++ 后台线程执行耗时任务，sin.output.append 输出日志。依赖 PyQt6 的 UI 组件按需延迟 import（try/except ImportError 后写入 sin.output）。uds-diagnostic 是复杂度最高的插件，将 ISO-TP 传输层（uds_isotp.py）、UDS 协议栈与服务编解码（uds_client.py）、DID 字典（dids.json）与主界面（main.py）分层组织，并通过 sys.path.insert(0, _HERE) 实现同目录模块导入。各插件之间相互独立、无共享代码，仅通过宿主 sin API 耦合。

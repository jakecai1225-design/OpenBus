- 插件入口统一实现 activate(context) 与可选 deactivate()，在 activate 内 try/except ImportError 延迟 import PyQt6 并回退到 sin.output 提示。
- plugin.json 固定包含 name/version/author/description/main/icon/activationEvents/contributes.commands 七个字段，commands.id 与 activationEvents 中的 onCommand 一一对应。
- 通过 sin.ui.create_window 创建顶层窗口，使用 QVBoxLayout/QFormLayout 组合表单，按钮点击回调集中绑定在文件末尾。
- 需要后台执行的耗时操作通过 sin.files.convert 提交任务并传入 on_progress/on_finished 回调，deactivate 中调用 sin.files.cancel 清理。
- CAN 帧收发统一走 sin.frames.send 与 context.on_frame 回调，按 ID 范围分派处理（如 0x700+ 心跳、0x80+ EMCY、0x580/0x600 SDO）。
- 可配置数据以 JSON 文件持久化（如 uds-diagnostic 的 dids.json），启动时合并 BUILTIN_* 常量与磁盘数据。

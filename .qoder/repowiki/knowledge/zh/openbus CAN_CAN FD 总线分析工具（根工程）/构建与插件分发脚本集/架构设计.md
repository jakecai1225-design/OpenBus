本模块由四个相互独立但协作的 Python 脚本组成，按职责分层：
- `build.py`：顶层构建入口，封装 CMake/Ninja/MinGW/Qt windeployqt 调用，通过 `argparse` 子命令（configure/build/run/debug/clean/rebuild/deploy/all/status/open）协调工具链路径（环境变量 `SIN_QT_DIR`/`SIN_MINGW_DIR`/`SIN_CMAKE_DIR`），自动检测 `tools/ninja/ninja.exe` 并优先使用 Ninja 生成器；编译前调用 `taskkill` 释放 openbus.exe 文件锁。
- `driver_tool.py` 与 `plugin_tool.py`：对称的包管理 CLI，分别处理 `.odp`（ZIP + driver.json + driver_<id>.dll）和 `.opk`（ZIP + plugin.json + main.py）格式，统一通过 `_emit` 输出单行 JSON 供 C++ QProcess 解析；install 流程采用“临时目录解压 → 校验 → 原子 move”模式，driver_tool 额外维护 `CHECKSUMS.sha256` 并在 install 前后做双重校验。
- `make_market.py`：聚合脚本，调用 driver_tool/plugin_tool 将 drivers/ 下的驱动与 plugins/ 下的插件打包为 .odp/.opk，并生成 `build/market/market.json`（schema 2），同时复制 assets 资源。
- `sin_host.py`：Python 插件宿主进程，通过 stdin/stdout 的 newline-delimited JSON-RPC 2.0 与主程序通信，动态 `importlib` 加载插件 main.py，维护 PluginContext（on_frame/register_command），在 PyQt6 可用时以 QTimer 轮询消息队列避免阻塞 Qt 事件循环。
依赖方向：make_market → {driver_tool, plugin_tool}；sin_host 通过共享 SDK 模块 `sin._transport` 与主程序解耦；各脚本之间无直接 import，仅通过命令行与文件系统交互。

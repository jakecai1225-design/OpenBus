- CLI 脚本统一通过 argparse 或 sys.argv 第一参数分派子命令，每个子命令实现为独立的 cmd_xxx(args) 函数并以 _emit(ok, **kwargs) 输出单行 JSON 结果。
- 驱动与插件包均采用 ZIP 容器 + 根目录 manifest（driver.json / plugin.json）+ 核心二进制/入口文件的约定结构，install 流程先解压到带前缀（.odp_/.opk_）的临时目录再原子 move 到目标目录。
- 名称字段使用正则 `^[a-z][a-z0-9-]*$` 进行合法性校验，防止非法字符进入包名或驱动 id。
- 外部工具调用统一通过 subprocess.run 执行，失败时打印彩色日志（build.py 中的 info/warn/fail/header）并返回非零退出码。
- Windows 环境下强制将 stdout 重编码为 UTF-8（sys.stdout.reconfigure(encoding="utf-8")），确保 C++ QProcess 能正确解析 JSON 管道输出。
- 插件生命周期通过显式 activate/deactivate 钩子管理，上下文对象（PluginContext）集中保存帧回调与命令注册表，异常被捕获后通过 log_error 上报而非抛出。

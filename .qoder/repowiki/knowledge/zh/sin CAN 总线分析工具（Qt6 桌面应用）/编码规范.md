- 核心业务逻辑集中在 sin_core 静态库中，UI 仅通过 sin_ui 静态库引用，使修改界面不触发 core 重编译。
- 硬件设备通过 ICanDevice 抽象 + CanDeviceManager 统一管理，UI 层只依赖统一的 frameGenerated 信号，屏蔽模拟器与真实硬件差异。
- 文件格式读写采用工厂模式（canfileio_factory / file_importer），新增格式只需实现对应 Reader/Importer 并注册到工厂。
- UI 组件通过 Qt 信号/槽向外暴露操作意图（如 SignalSendTab 的 sendAllRequested/sendSingleRequested），避免直接调用 core 层对象。
- 长耗时或线程间通信使用 utils/message_queue.h 的无锁队列配合 QTimer 在主线程批量消费，避免阻塞 UI。
- 资源（QSS 样式、SVG 图标、配置文件）集中放在 resources/ 并通过 resources.qrc 打包，运行时通过资源路径访问。

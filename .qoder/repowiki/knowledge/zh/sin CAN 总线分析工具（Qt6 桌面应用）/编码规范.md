- 核心能力以静态库形式拆分：`sin_core` 暴露公共头路径给 UI 层，UI 改动仅重编译 `sin_ui`，避免触发 core 重编译。
- 预编译头（PCH）按层分别声明：`sin_core` 仅包含无 Widget 的基础 Qt 头，`sin_ui` 包含完整 Widget 头列表，以缩短编译时间。
- UI 组件通过 `setDbcManager(DbcManager*)` 等 setter 注入依赖，而非构造函数直接持有，便于测试与复用。
- 跨层通信统一通过 Qt 信号槽：SignalSendTab 暴露 `sendAllRequested`/`stopAllRequested`/`sendSingleRequested`/`sendRowRequested` 等信号，上层容器负责连接实际发送逻辑。
- DBC 消息与信号数据通过 `core/dbcdata.h` 中的 `DbcMessage`/`DbcSignal` 结构体传递，UI 层只读访问其 name/id/dlc/signalList/valueTable 字段进行渲染。
- 十六进制 ID/数据统一通过 `formatIdHex`/`formatDataHex`/`parseHexData` 等静态辅助函数转换，保证显示格式一致。

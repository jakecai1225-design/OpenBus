项目采用 CMake + Qt6 构建，顶层 CMakeLists.txt 定义 sin 工程并 include third_party/Dependencies.cmake；src/CMakeLists.txt 将代码拆为三个目标：sin_core（静态库，含 core/models/utils 层）、sin_ui（静态库，封装所有 UI 组件）、sin（可执行入口 main.cpp）。核心分层清晰：core/candevice* 通过 ICanDevice 抽象统一 ZLG/PEAK/Kvaser/TongXing/SLCAN 等硬件及内置 CanSimulator，由 CanDeviceManager 在运行时切换；core/canfileio 以 canfileio_factory 工厂模式实现 ASC/BLF/CSV/PCAP/TRC 读写；core/file_import 提供 Importer 接口用于 DBC/ASC/CSV/BLF 数据导入；ui 层以 MainWindow 为主容器，Tab 页（signalsendtab、recordtab、playbacktab、dbcdetailtab、udsview、canopenview、measurementsetupview、deviceconnectiontab）+ 侧边栏 panels + 底部面板 bottompanel 组成；models 层提供 CanTraceModel / CanFilterProxyModel 作为 Qt 数据模型；utils 提供消息队列、SVG 图标、日志等通用能力。UI 与 core 之间通过信号/槽解耦（如 SignalSendTab 发出 sendAllRequested/sendSingleRequested 等信号），DbcImportDialog 通过 DbcManager 搜索已加载 DBC 中的 CAN ID/信号名并返回选中列表。构建时 driver/ 下的 DLL（zlgcan.dll、ZPSCANFD.dll 等）通过 POST_BUILD 拷贝到 exe 同级目录，满足运行时依赖。

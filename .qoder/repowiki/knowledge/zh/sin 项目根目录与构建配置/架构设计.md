根目录为整个 sin 项目的顶层入口，采用 CMake 作为构建系统：CMakeLists.txt 声明 Qt6 Widgets 依赖并启用 AUTOMOC/AUTOUIC/AUTORCC，通过 add_subdirectory(src) 将源码子目录纳入构建；README.md 详细描述了三层架构（core/models/ui/utils）及 VS Code 风格的无边框窗口、QDockWidget 停靠面板、ActivityBar + SideBar 布局；.gitignore 统一过滤构建产物、Qt 自动生成文件（moc_*/ui_*/qrc_*）、IDE 配置等。当前模块仅包含元数据与构建清单，实际 UI 重构（菜单栏、侧边栏折叠区、Wireshark 三栏 Trace、可停靠 QDockWidget）的实现位于 src/ 子目录中。

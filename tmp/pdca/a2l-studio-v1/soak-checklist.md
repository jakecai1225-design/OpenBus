# Soak — A2L Studio + XCP Studio P0/P1

- [ ] Open A2L Studio from sidebar; VS Code four-piece chrome (activity, side bar, editor tabs, OUTPUT).
- [ ] File → Open sample A2L; Objects tree shows MEASUREMENT / CHARACTERISTIC.
- [ ] Edit an ECU_ADDRESS; Save; Check has no errors.
- [ ] Compare against a second A2L; Export CSV / slim A2L.
- [ ] Apply → XCP Studio; XCP opens Setup with the same A2L path.
- [ ] XCP: set Master/Slave IDs; Connect (slave must answer CONNECT).
- [ ] Measure: check signals; Start poll; values update; sparkline moves.
- [ ] Start/Stop DAQ lite (START_STOP_SYNCH); OUTPUT shows TX/RX.
- [ ] Calibrate: write scalar with confirm; MAP cell write; Switch cal page 0/1.
- [ ] Record: start, poll a few samples, Export CSV and MDF subset text.
- [ ] XCP File → Edit in A2L Studio returns to Objects.
- [ ] Open A2L Studio then XCP Studio together; first window stays open.

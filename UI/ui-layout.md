# sin UI 布局描述规范

> **用途**：本文件是 sin 软件 UI 布局的唯一权威描述。所有 UI 变更需先修改本文件，
> 经浏览器原型确认后，再进行 Qt 代码实现。
>
> **工作流**：修改本描述 → 渲染 ui-prototype.html 确认 → Qt 代码实现

---

## 1. 窗口总览

```
无边框窗口 (Qt::FramelessWindowHint)
├── MenuBar          — 菜单栏（兼标题栏，可拖拽/双击最大化）
├── LeftDock         — 左侧栏（ActivityBar + SideBar）
├── CenterArea       — 中央编辑区（可拆分标签页）
├── RightDock        — 右侧栏（属性/统计）
├── BottomDock       — 底部栏（终端/输出/问题）
└── StatusBar        — 状态栏
```

### 1.1 窗口属性
- 标题: `sin - CAN/CAN FD 报文分析工具`
- 默认尺寸: 1400 × 900
- 窗口标志: `Qt::Window | Qt::FramelessWindowHint`
- 边缘缩放: 5px 命中区，支持 Aero Snap
- 菜单栏拖拽: 空白区域按住左键拖动窗口
- 菜单栏双击: 切换最大化/还原

## 2. MenuBar 菜单栏

**布局**: 水平，高度 28px，背景 `#2D2D2D`，文字 `#e0e0e0`

```
[文件(F)] [视图(V)] [工具(T)] [帮助(H)]          [─] [□] [✕]
└── 菜单项 (左侧)                                └── 窗口按钮 (右上角)
```

### 2.1 菜单项
| 菜单 | 子项 |
|------|------|
| 文件 | 打开文件... · 退出 |
| 视图 | ☑左侧栏 · ☑底部栏 · ☑右侧栏 · 重置布局 |
| 工具 | ●录制 · ▶播放 · ⏸暂停 · ⏹停止 · 清空Trace · ☑自动滚动 · 模拟器开关 |
| 帮助 | 关于 sin |

### 2.2 窗口按钮
| 按钮 | 图标 | 尺寸 | Hover |
|------|------|------|-------|
| 最小化 | ─ | 46×28 | `#3D3D3D` |
| 最大化 | □ | 46×28 | `#3D3D3D` |
| 关闭 | ✕ | 46×28 | `#e81123` (红) |

## 4. CenterArea 中央编辑区

**组件**: `SplitEditorArea` — 支持标签页拆分

### 4.1 标签页
| 标签 | 内容 |
|------|------|
| 📋 Trace | Wireshark 风格三栏报文追踪 |
| 📈 Graphic | 信号波形图 |

### 4.2 标签页右键菜单
- 向右拆分
- 向下拆分
- 关闭此拆分组

### 4.3 Trace 标签页内部布局

```
┌──────────────────────────────────────────────┐
│ FilterBar: [过滤表达式输入框] [清除]           │  ← 固定高度
├──────────────────────────────────────────────┤
│ Time       │ Ch │ Dir │ ID    │ DLC │ Data        │ Flags │
│ 0.000123   │ 1  │ Rx  │ 0x123 │ 8   │ 01 02 03... │ ---   │
│ 0.000456   │ 1  │ Rx  │ 0x456 │ 8   │ 11 22 33... │ FD    │
│ ...        │    │     │       │     │             │       │
├──────────────────────┬───────────────────────┤
│ 帧结构                │ 信号解析               │  ← 底部 25%
│                      │                       │
│ Time:       0.000123 │ EngineStatus  (0x123) │
│ Channel:    1        │ ───────────────────── │
│ Direction:  Rx       │                       │
│ ID:         0x123    │ EngineRPM:    1234.500│
│ DLC:        8        │ ThrottlePos:   45.200│
│ Data:       01 02... │ CoolantTemp:   89.000│
│ Flags:      ---      │                       │
│                      │                       │
│ Hex: 01 02 03 04 05..│                       │
└──────────────────────┴───────────────────────┘
  ← 左 50% →           ← 右 50% →
```

#### 4.3.1 FilterBar
- 水平布局: QLineEdit (stretch) + QPushButton(清除)
- 占位文字: `输入过滤表达式...`

#### 4.3.2 TraceView (报文列表)
- `QTableView`，等宽字体 10pt
- 可排序、可移动列头、右键列头菜单
- 列: Time(100) | Channel(40) | Direction(40) | ID(120) | DLC(60) | Data(300) | Flags(80)

#### 4.3.3 FrameInfoWidget (帧结构)
- 标题: `帧结构`，高 28px
- 内容: `QPlainTextEdit` 只读，等宽字体 10pt
- 格式: `字段名(10字符宽):  值` + Hex 单行

#### 4.3.4 SignalDecodeWidget (信号解析)
- 标题: `信号解析`，高 28px
- 内容: `QPlainTextEdit` 只读，等宽字体 10pt
- 格式: 报文名 + 分隔线 + `信号名(对齐)  值 单位`
- 无 DBC 时: 显示 `(未加载 DBC 文件)`
- ID 未定义时: 显示 `ID 0xXXX 未在 DBC 中定义`

### 4.4 Graphic 标签页
- `GraphicView` 自定义绘图
- 时间轴横坐标，信号值纵坐标
- 支持多信号叠加、滚轮缩放
